# Структура способностей ДнД 5.5 — план работ

Гриллинг 2026-09-06, два раунда, все ответы владельца — «да». Разбор полного
текста ChatGPT — в треде (рамка: лист, а не движок; ярд — «UI покажет
и отследит», а не «движок вырезолвит»).

## Залоченные решения

1. **ChoicePool гетерогенный**: `from` — entryId любых типов (умения,
   заклинания, навыки). Валидация «N выбрано». Круги и подготовка —
   свойства самих заклинаний, пулу не нужны.
2. **Миграция, не руки**: аудит компендиума → список детерминированных
   («N раз за отдых») на подпись → миграция проставляет `cost`. Первые:
   «Исцеляющие руки» (1/долгий), «Откровение Небес» (1/долгий),
   «Врождённое чародейство» (2/долгий).
3. **Промпт опций**: `options: string[]` у стоимости, кнопки в окне траты,
   без условий (условия — дверь в движок, закрыта).
4. **Concentration/ritual — не сейчас**: это заклинательная сторона. Cost
   проектируем так, чтобы флаги легли потом.
5. **Граница продукта**: движка событий нет как решение, не как «потом».
   Триггеры-строки не срабатывают сами, модификаторы не применяются сами.
6. **Prerequisites-минимум**: уровень класса + наличие фичи + стат,
   AND-списки. Недоступное видно, но приглушено с причиной. OR/NOT — нет.
7. **Пулы единые**: свои — в тот же `resourceUsed`, ключ `feature:{entryId}`.
   Витрина одна: лента по тратящим строкам + «Ресурсы» + тофу-пипсы.
   Классовые пулы остаются классовыми, механика общая.
8. **Дикий облик**: форма — ссылка `{entryId, name}` (как спутники), выбор —
   из пула зверей со строгим CR-гейтом по уровню, открытие — тем же превью.
9. **Редактор**: флаг «свой ресурс» + применения + «восполнение:
   короткий/долгий» — в строке стоимости умения.

## Сущности (итоговая модель)

- `DndCost` += `ownResource?: boolean` (пул выводится, ключ `feature:{entryId}`);
  `amount`, `per` уже есть. `kind: "uses"` обретает механику.
- `ChoicePool { count, from: entryId[], gates? }` — новый узел, один на всех.
- `prerequisites[]` — минимум (см. п.6).
- `trigger?: string` — строка для показа.
- `options?: string[]` у стоимости — промпт в момент траты.
- Definition/instance: определения в справочнике, потраченное — в листе.
  Снапшот-фолбэк от мёртвых ссылок сохраняется.

## Отложено / отрезано (с обоснованием в треде)

- Event bus, триггеры-код, expressions-интерпретатор, target/condition-сущности,
  Cost.formula, modifies/excludes, авторские tags, duration-узел.
- Concentration/ritual-флаги — следующим заходом.
- Слияние «Ресурсов» в «Особенности» — отложено владельцем.

## Порядок работ

1. `DndCost`: флаг + механика `uses` (вывод пула, трата из строки, сброс
   по `per` на отдыхе).
2. Тофу-пипсы поверх пулов (`TofuPip`: целая/блеклая голова; слепок
   маскота под 18px, не весь SoyMan).
3. Аудит компендиума → список → подпись → миграция трёх+ способностей.
4. ChoicePool: модель + UI выбора с prerequisites + пул зверей для облика.
5. Промпт опций в окне траты.
6. Флаг в редакторе стоимостей.

## Тесты приёмки (батарея)

Rage, Bardic Inspiration (+передача), манёвры, метамагия, воззвания —
без движка; Cunning Strike — промптом; Wild Shape — ссылкой; кастомный
Void-тест — честно вне скоупа.
