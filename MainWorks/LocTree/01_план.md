## 4. Поведение
- Несколько корней (`parent_id=null`) — один лес, слои по глубине от корней.
- Новые локации / смена parent извне — автопозиция, ручные не затираем.
- Архивные — как в дереве (скрыть/пометить, по текущему поведению).
- Пустое — плейсхолдер «создайте первую локацию». 100+ нод — Fit без виртуализации (beta).
