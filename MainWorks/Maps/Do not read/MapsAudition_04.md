## Аудит по четырём точкам зрения

### 1. Графический дизайнер-перфекционист (опора: `design_revision.md`)

**P0-3. Превью карты в списке проходит дуотон + халфтон — нарушение §1.13 и §7.**
`MapsListPage.tsx:50–59` — плитка `campaign-tile-cover cover-halftone` + `cover-art-image` применяет к `map.thumbnail` общий дуотон и растр. Террейн теряет.identity: вода сливается с равниной, лес — с болотом. **§1.13** («изображение-содержимое не трогается никогда») и **§7** (поле — фиксированная палитра, не duotone) нарушены. План: отдельный класс `.map-tile-art` без `cover-photo/cover-halftone`, `background-image` как есть.

**P1-1. Акцент-бюджет превышен в 3–4 раза — §1.8.**
В тулбаре (`MapEditorPage.tsx:798–870`) одновременно `primary`-кнопки: активный инструмент + активный размер кисти + раскрытый «Генератор» + раскрытый «PNG» + «Сгенерировать» + «Скачать PNG». До 6 акцентных пятен. §1.8 — один горячий объект на содержимое страницы. План: `primary` только у главного CTA контекста; остальное — `aria-pressed` + обводка `ink`, не `accent`.

**P1-2. Выбранная кисть залита `--accent` — §1.3 и §7.**
`MapEditorPage.tsx:901–908`: `border: 2px solid var(--accent)`. Нарушает §1.3 (везде 1 px) и §7 («выбранная кисть — выделением-обводкой, а не заливкой акцентом»). План: `1px solid var(--ink)` + внешний маркер (уголок/подчёркивание).

**P1-3. Координаты — не тот голос. §1.5.**
`render.ts:237`: `font: ... var(--font-ui, sans-serif)`. По §1.5 координаты — Label (Oswald, капс, трекинг .08em). `--font-ui` глобально прибит и по §2 принадлежит режиму. План: `500 …px Oswald` + `letter-spacing: 0.08em`.

**P1-4. Палитра сливается: равнина/пустыня/холмы и лес/болото — §7.**
`MAP_TERRAIN_FILL`: `plain #C2B489` vs `desert #D3BC87` vs `hills #A89A7C` — три бежевых рядом (dLum 0.516/0.459/0.329 — близко); `forest #75946F` vs `swamp #7E9070` — два зелёных (dLum 0.261/0.183, дейтеранопия 0.006). На ЧБ-печати и при дейтеранопии не различимы. §7 освобождает от цвета кодирования типа, но не от читабельности. План: развести яркости; болото `#5F7D72` (уже сделано в отчёте MapsAudition_01).

**P0-7. PNG-экспорт неполный — §7 Печать.**
Отсутствуют: легенда террейна с названиями, `cell_lore` («1 клетка = …»), координаты по умолчанию, подбор плотности под A4/A3. Регион 60×44 при 32 px/клетку = 1920×1408 px — впритык к A4, на проекторе мыльно. Без легенды мастер не может объяснить игроку, что такое «лава» или «болото». План: легенда + `cell_lore` + координаты (дефолт ВКЛ для печати) + выбор плотности.

**P1-9 / P2-3. Легенда и подсказки террейна — UX дизайнера.**
Ряд кистей — цветные квадраты 26×26 с `title`. Название текущего террейна — мелкий `muted`. Новый мастер не расшифрует карту. План: постоянная collapsible-легенда (цвет + название).

### 2. Программист (код, уязвимости, производительность)

**P0-1. Одиночный клик не попадает в историю — потеря данных.**
`MapEditorPage.tsx:331–342` `paintAt()`: флаг `changed` вычисляется **внутри** `setCells` апдейтера (асинхронно), а возвращается синхронно. `return changed` почти всегда даёт старое значение. Вызывающий `onPointerDown` (`557`) и тач (`611–612`) делают `if (paintAt(...) && strokeRef.current) strokeRef.current.changed = true` — при клике в одну клетку условие ложно, шаг в историю не идёт. `endStroke()` ничего не пушит. История эфемерная (не переживает перезагрузку), `beforeunload` нет, при `saveState.kind === "error"` только текст без кнопки «Повторить» — закрыл вкладку = потеря.

**P0-2. Список тащит миниатюры всех карт — тормоз + трафик.**
`server/src/routes/maps.ts:27–36`: `META_COLUMNS` включает `thumbnail` (до 300 000 символов). `GET /` отдаёт его на каждую карту. 20–50 карт = единицы–десятки МБ JSON за один запрос. План: `GET /` без thumbnail; точечная подгрузка через `GET /maps/:id/thumbnail`.

**P0-6. Thumbnail — произвольная строка в `backgroundImage` (CSS-инъекция + bloat).**
Сервер принимает любую строку ≤300k (`mapsValidation.ts:173–178`), клиент вставляет `style={{ backgroundImage: url("...") }}` (`MapsListPage.tsx:56`). Закрывающая кавычка позволяет вырваться из `url()` в соседние CSS-свойства. План: вайтлист `data:image/png;base64,` + проверка base64/размера/сигнатуры PNG; иначе 400.

**P1-5. Рендер всего поля на каждый hover — 60 FPS не обеспечены.**
`renderMap` перерисовывает всё: гексы — два полных прохода `traceCell+fill`, без culling по вьюпорту, на каждое движение мыши (меняется `hover`). 100×100 гексов ≈ 20k path-операций за `mousemove`. Плюс `paintAt` клонирует `Map + Set` на каждый `pointermove`, автосейв рисует `renderThumbnail` каждые 800 мс. План: culling; hover — отдельным лёгким слоем без полного rerender; дроссель; thumbnail — только при паузе ≥2–3 с.

**P1-6. Сохранения гоняют без версий — гонка PUT.**
Два быстрых мазка = два overlapping `PUT` (`250–262`), побеждает поздний ответ, не поздний мазок. `lastSavedRef` обновляется в `then`, порядок не гарантирован. План: монотонный `saveSeqRef`; устаревший ответ игнорируется.

**P1-7. Битый blob молча становится пустой картой.**
`parseCellsBlob` (`render.ts:64–76`): `catch` → пусто, `v !== 1/2/3` → пусто, без сигнала. Загрузка нормализует эталон; первая же правка перезапишет сервер — исходные данные потеряны без предупреждения. План: строгий `cellsBlobStatus()` на загрузке; плашка «данные повреждены»; автосейв gated на разрешение.

**P0-4. Потерянную камеру не вернуть без перезагрузки.**
`fitCamera` только при монтировании и `resize`. Кнопок «Вписать»/«+»/«−» нет; панорама колесом/средней/пробелом может увести поле в пустоту. На таче/ноуте без колеса — тупик. План: кнопки зума + «Вписать» + хоткеи `0`/`+`/`−`.

**P1-8. В редакторе нет переименования/ресайза/дубля/удаления.**
`PUT` умеет `name/cell_lore/width/height/scale`, но UI редактора их не правит: имя только при создании, размер — тоже, дубля нет, удаление — только из списка. Ошибся в 40×30 → удаляй и рисуй заново. План: «Настройки» (имя, масштаб, подпись, W/H с кропом и `fitCamera`), «Дублировать», «Удалить» с `useConfirm`.

**P1-6. `translateMapError` — гигантская таблица регэкспов.**
`mapTypes.ts:69–99`: ~30 регэксов в цикле, некоторые перекрываются (`/out of bounds/i` ловит слишком широко). Обслуживание затруднено, нет группировки по домену. План: сгруппировать по домену (валидация, API, сеть), добавить комментарии.

**Прочее:** `MAP_TOOL_ORDER` содержит `road`, но `MAP_TERRAIN_FILL["road"]` возвращает `undefined` (дорога — бит-оверлей, не террейн). `COALESCE` для `parent_map_id`/`thumbnail` не позволяет сбросить в NULL. Реф-шаблон (`undoRef`/`redoRef`/`selectedRef`/`deleteSelectedRef`/`fitCameraRef`/`zoomByRef`) — хрупкий, зависит от синхронизации рефов каждый рендер.

### 3. Придирчивый пользователь («КАК ЭТО У ВАС НЕТ ТАКОГО?!»)

**P2-8. «Сбросить фильтры» только в пустом состоянии.**
`MapsListPage.tsx:293–307`: кнопка «Сбросить» есть только когда `filtered.length === 0` при активных фильтрах. Если фильтры вернули результат, но пользователь хочет быстро сбросить — кнопки нет. План: всегда показывать «Сбросить» при активных фильтрах.

**P1-10. Правая кнопка «зарезервирована» = молчит.**
`onContextMenu: preventDefault` + в `onPointerDown` правая не обрабатывается (только 0/1). Пользователь жмёт ПКМ — тишина, в подсказке (`1035`) об этом мелким шрифтом «зарезервирована». План: честный ластик (временный) или тост «скоро».

**P2-7. Зум/пан для клавиатуры и скринридера.**
Canvas без `role="img"`/`aria-label` (появился в P2-7 отчёте 01, но в `MapEditorPage.tsx` нет живого региона, объявляющего текущий инструмент). Хоткеи есть (`B/G/E/I/R/M/T/V`, `Ctrl+Z`, `+/-/0`), но фокус/объявление кисти для SR нет. План: `role="application"` + `aria-label`, живой регион `aria-live="polite"`.

**P2-8. Счётчик `filtered/maps` не кликабелен.**
`MapsListPage.tsx:261–263`: `{filtered.length} / {maps.length}` — текст, не интерактивный. Невозможно быстро вернуться из глубокой фильтрации. План: «Сбросить» как кнопка рядом.

**P2-8. PNG-имя с кириллицей/пробелами.**
`MapEditorPage.tsx:317`: санитизация только `\/:*?"<>|`, но кириллица и пробелы проходят. План: замена на `_`.

**P1-9. Пипетка не берёт дороги, ластика под дороги нет.**
`singleAction`/`Alt+клик` читают только `terrain`, `roads` игнорируют. Дорогу в одну клетку не взять и не стереть точечно. План: пипетка берёт оба слоя; `Alt+Shift` — снять дорогу.

**P2-8. Координатный readout не объяснён.**
Под полем: «B12 · 24 пт/кл» — что такое «пт/кл»? Нового мастера не расшифрует. План: подсказка «точек на клетку; подписи рисуются от 18».

### 4. Мастер игры (подготовка к игре, печать)

**P0-7. Печатная карта неиграбельна «из коробки».**
PNG: фикс 32 px/клетка, сетка вкл / координаты выкл по умолчанию, легенды нет, `cell_lore` не вшит. Мастер не может сказать игроку «идёте в B12» — координат на бумаге нет. Регион 60×44 при 32 px = 1920×1408 px — на А4 впритык, на проекторе мыльно. План: легенда + `cell_lore` + координаты ВКЛ + плотность 24/48/96 px.

**P2-1. Нет линейки расстояний.**
«Сколько до гор?» — считать клетки глазами. Соседи/дистанции в `grid.ts` есть (`neighbors`, `brushDistance`), но UI-линейки нет. План: инструмент «Линейка» (клик-клик, клетки + `cell_lore`-пересчёт).

**P2-2. Нет подписей/маркеров городов и данжей.**
Слой один (террейн + бит дорог). Карта без «Вотердип» и «логово» — немая схема; генератор даёт только пятна. План: слой подписей (текст + точка-маркер, минимум 200), в PNG — вшиты.

**P1-8. Не можно переименовать/ресайзнуть карту после создания.**
Ошибся в масштабе 40×30 → удаляй и рисуй заново. Нет дубля для эксперимента. План: «Настройки» в редакторе (переименовать, подпись, размер с предупреждением об обрезке, дублировать).

**P2-5. Показ на стол — только флаг видимости.**
`SendMapToSessionModal` wired только к `LocationMap`, к `/maps/:id` — нет. Мастер говорит «откройте раздел Карты», пуша нет. План: кнопка «Показать игрокам» (флаг + тост/ссылка). ОТЛОЖЕНО → `На_будущее.md` п.1.

**Печать/экспорт.** JSON-обмен есть, но не для печати. Миникарта есть, но не печатается. План: в PNG — легенда + координаты + `cell_lore` + выбор плотности; позже — разбивка на листы A4/A3.

**Масштабная линейка и «клетка = …».**
Пресеты масштаба (`MAP_SCALE_PRESETS`) задают `cellLore` («500 км», «2 км», «5 м»), но на карте эта информация не отображается без координат + без легенды. План: легенда как минимум содержит «1 клетка = …».
