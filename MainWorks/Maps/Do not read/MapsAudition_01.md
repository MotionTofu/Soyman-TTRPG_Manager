## P0 — критично (данные, безопасность, тупики)

### P0-1. Одиночный мазок может не попасть в историю (потеря работы) — [Код]
- `MapEditorPage.tsx:331-342` `paintAt()`: флаг `changed` выставляется ВНУТРИ апдейтера `setCells`, а возвращается синхронно. Апдейтер выполняется позже рендера, поэтому `return changed` почти всегда отдаёт старое значение.
- Вызывающие места `MapEditorPage.tsx:557` (`onPointerDown`) и тач `611-612` делают `if (paintAt(...) && strokeRef.current) strokeRef.current.changed = true` — при клике в одну клетку условие ложно, шаг в историю не идёт. `endStroke()` (`349-354`) тогда ничего не пушит.
- Добивка: истории нет после перезагрузки (эфемерная, `164-166`), `beforeunload`/локального бэкапа нет, при `saveState.kind === "error"` (`726`, `259-261`) только текст «попробуем при следующем мазке» без кнопки повтора — закрыл вкладку до следующего мазка = потеря.
- План: переписать `paintAt` на вычисление `changed` ДО `setCells` (чистая функция от `cellsRef.current`), дублировать логику в тач-пути; добавить `beforeunload` при `dirty/saving`; кнопку «Повторить сохранение»; позже — версионирование/снапшоты «веха».

### P0-2. Список тащит миниатюры всех карт (тормоз + трафик) — [Код]
- `server/src/routes/maps.ts:27-36`: `META_COLUMNS` включает `thumbnail` (до 300 000 символов, `mapsValidation.ts:43`), и `GET /` отдаёт его на каждую карту. 20–50 карт = единицы–десятки МБ JSON за один запрос списка.
- План: убрать `thumbnail` из списка (отдельный `GET /maps/:id/thumbnail` или `?withThumb=0/1`), на клиенте — ленивая подгрузка/кэш; лимит/пагинация списка.

### P0-3. Превью карты проходит дуотон/халфтон как декор (порча содержимого) — [Дизайн, Мастер]
- `MapsListPage.tsx:50-59`: плитка `campaign-tile-cover cover-halftone` + `cover-photo/cover-art-image` применяет к `map.thumbnail` общий дуотон и растр.
- Нарушает `design_revision.md` §1.13 («изображение-содержимое не трогается никогда») и §7 («UI вокруг — по инварианту, поле — фиксированная палитра»). Карту перестают узнавать: цвета террейна едут, легенда врёт.
- План: для миниатюр карт отдельный класс без `cover-photo/cover-halftone/cover-art-image`-фильтров, `background-image` как есть; проверить тёмные режимы (палитра фиксирована, фон — `paper`).

### P0-4. Потерянную камеру не вернуть без перезагрузки — [UX, Мастер]
- `fitCamera` (`MapEditorPage.tsx:385-410`) только при монтировании карты и `resize` (`403-410`). Кнопки «Вписать»/«1:1»/«+ / −» нет; панорама средней/пробелом (`531-537`) и зум колесом/щипком (`473-489`, `646-665`) могут увести поле в пустоту.
- На таче/ноуте без колеса это тупик. За столом — срыв показа.
- План: кнопки зума + «Вписать» в тулбар + хоткеи (`0`/`+`/`-`), клик по координатам не нужен; состояние камеры не хранить в истории.

### P0-5. «Сгенерировать» затирает ручную работу без подтверждения — [UX]
- `generate()` (`269-274`) молча заменяет клетки; подпись (`975-978`) честно говорит «затрёт», но диалога нет. Undo спасает только до перезагрузки.
- План: `useConfirm` перед генерацией при непустых клетках («на карте есть ручная роспись»), в диалоге — сид/параметры сводкой; плюс P0-1 (иначе подтверждение — единственная защита).

### P0-6. Thumbnail — произвольная строка в `backgroundImage` (CSS-инъекция + бloat) — [Код]
- Сервер принимает любую строку ≤300k (`mapsValidation.ts:173-178`), клиент вставляет `style={{ backgroundImage: url("...") }}` (`MapsListPage.tsx:56`). Закрывающая кавычка позволяет вырваться из `url()` в соседние CSS-свойства.
- План: вайтлист `data:image/png;base64,` (+ проверка base64/размера/сигнатуры PNG), иначе 400; на клиенте рендерить только прошедшие префикс, остальное — заглушка; тест на `");...`.

### P0-7. Печатная карта неиграбельна «из коробки» — [Мастер]
- PNG (`292-327`): фикс 32 px/клетка, сетка вкл / координаты выкл по умолчанию, текст `1004-1006` «Легенда не вшивается». Нет: легенды террейна, линейки «1 клетка = …» (`cell_lore` есть в данных, на экспорт не идёт), шкалы под миниатюры (местность 5 м ≠ дюймовая сетка), раскладки под A4/A3, `@media print`.
- Регион 60×44 → ~1920×1408 px: на А4 впритык, на проекторе мыльно; мастер не может сказать «идёте в B12», потому что координат на бумаге нет.
- План: в PNG вшивать легенду + `cell_lore` + опциональные координаты (дефолт обсудить: координаты ВКЛ для печати); выбор плотности (24/48/96 px); позже — линейка расстояний и разбивка на листы.
