## Зафиксировано (раунд 1)
1. **Сущность первого уровня.** Таблица `maps`, список свой. Привязка — многие-ко-многим: одна карта к нескольким сеттингам/кампаниям/локациям (таблица-связка `map_bindings`: `map_id + target_type + target_id`).
2. **Навигация.** Пункт «Карты» в `GM_NAV_ITEMS` (`AppShell.tsx`) — под «Графом связей». У игрока раздел есть, видны только карты с флагом видимости от мастера.
3. **Сетка — свойство навсегда.** Выбирается при создании (квадраты / гексы), смена после — только с очисткой раскраски и подтверждением. Дефолт ориентации гексов — под вопросом раунда 2 (предложение: pointy-top).
4. **Масштаб — ярлык-пресет в фундаменте.** Иерархия (вложенность, провал кликом в дочернюю карту) — НЕ фундамент, вынесена в `Иерархия_карт.md`.
5. **Пресеты масштаба (приняты предварительно):** Планета 24×18 (клетка 500 км) / Континент 40×30 (100 км) / Страна 50×36 (20 км) / Регион 60×44 (2 км) / Населённый пункт 40×30 (20 м) / Местность 50×36 (5 м, опция 5 футов). Масштаб меняет дефолтный размер, подпись «1 клетка =» и порядок кистей на виду; все кисти доступны везде.
6. **Генератор MVP:** суша/вода + горы/лес по сиду, ползунки море/горы/лес, сид хранится, перегенерация воспроизводима. Реки/дороги/города — руками поверх, автоген — позже.
7. **Хранение:** тайловая матрица в SQLite (`maps` + клетки JSON-blob), экспорт PNG в фундаменте, импорт подложки — позже. **Undo/redo — сразу в фундаменте** (по требованию владельца).
8. **Цветовое исключение** как у Полотна (§6 `design_revision.md`): спокойная фиксированная палитра террейна, бюджет акцента на неё не тратится; UI вокруг карты — по общему инварианту (0 радиусов, без теней, 1px, голоса шрифтов).

## Зафиксировано (раунд 2)
9. **Привязки:** схема `map_bindings` закладывается сразу, UI привязок — следующим шагом. В фундаменте карты стоят одни.
10. **Видимость:** флаг `player_visible`, по умолчанию скрыта; тумблер в шапке редактора + фильтр списка. Тумана войны нет.
11. **Сетка:** гексы pointy-top, координаты offset `A1…` для обеих сеток; клетка масштабируется под вьюпорт, зум колесом; линейки нет.
12. **Палитра MVP — 10 кистей:** глубокая вода, мелкая вода, равнина, лес, холмы, горы, пустыня, лёд, **болото, дорога** (добавлены по требованию). Без проходимости: всё — краска.
13. **Undo/redo:** глубина 50, шаг = мазок / заливка / генерация; `Ctrl+Z / Ctrl+Shift+Z` + кнопки; redo сгорает при новом мазке; история эфемерная.
14. **Техника:** один `<canvas>` 2D; маршруты `/maps` (плитка) и `/maps/:id` (редактор); автомасштаб + зум колесом + панорама правой кнопкой/пробелом.
15. **Инструменты фундамента:** кисть 1/2/3, заливка, ластик (=равнина), пипетка, сетка/координаты вкл-выкл, очистка с подтверждением. Без слоёв, выделений, подписей.

16. **Дорога — бит-оверлей** (`road: bool` поверх террейна), единственное исключение из «без слоёв». Рисуется линией по центрам соседних дорожных клеток.
17. **Генератор:** value-noise 4 октавы + фиксированный радиальный спад; ползунки море 20–80 (55) / горы 0–40 (12) / лес 0–60 (30); сид редактируемый + «кубик»; болото/дороги/лёд — только руками.
18. **Видные кисти по масштабам:** Планета — глуб.вода/мелк.вода/равнина/горы/лёд; Континент/Страна/Регион — мелк.вода/равнина/лес/холмы/горы + остальные; Пункт/Местность — дорога/равнина/лес/мелк.вода/холмы + остальные.
19. **PNG:** клетки + дороги, 32 px/клетка; чекбоксы сетка (дефолт вкл) / координаты (дефолт выкл); имя файла предлагает `map-<name>`, пользователь правит.
20. **Список/создание:** `/maps` плиткой (плашка-инверсия, миниатюра тем же рендером, чипы сетки/масштаба, размер+дата моноширинным); поиск + фильтр масштаб/сетка + сортировка А–Я/недавние; пусто — `EmptyState`; создание: имя + сетка (пометка «навсегда») + масштаб + W/H 8–100 с дефолтами пресета.
21. **Управление:** левая — рисовать (клик = 1 клетка), средняя/пробел — панорама, колесо — зум к курсору, `Alt+клик` — пипетка; тач 1 палец — рисовать, 2 — пан/зум. **Правая кнопка зарезервирована под будущее контекстное меню**, в фундаменте без действия (без браузерного меню — глушим).
