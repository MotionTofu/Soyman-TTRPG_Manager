## P0 — критично (делать первым, до всего остального)

### P0-1. Секретный слой утекает игрокам: стрип чистит только blob v3, клиент всегда пишет v4 [К, М]

- `server/src/routes/maps.ts:96`: `stripCellsForPlayer` — `if (... blob.v !== 3) return cellsStr;`
  (сырой blob уходит как есть).
- `client/src/maps/render.ts:1260`: `serializeCells` всегда пишет `v: 4`.
- Итог: **любая актуальная карта, отданная игроку через `GET /maps/:id`, содержит
  секретные двери и все ловушки открытым текстом.** Чистка работает только для
  музейных v3.
- Тест `server/src/routes/maps.api.test.ts:198` проверяет стрип только на v3 —
  поэтому набор зелёный и беду не видит.
- Исправление: стрипать двери/ловушки независимо от версии (v3 и v4, а лучше —
  по наличию полей, а не по номеру версии); тест дополнить кейсом v4
  (секретная дверь + `secret:true` + `trapped` + ловушки + реки/маркеры).
- Вопрос владельцу (см. § «К обсуждению», п.1): имена комнат сейчас видны игрокам
  по спеке (пакет A §6) — подтверждаем, что так и надо?

### P0-2. Импорт JSON затирает карту без подтверждения [К, П, М]

- `MapEditorPage.tsx:1331` (`importJson`): файл сразу заменяет клетки, объекты и
  параметры генератора. Ни confirm-диалога (как у генерации суши/данжа), ни
  предпросмотра. Единственная защита — эфемерная история (умирает при
  перезагрузке).
- Исправление: confirm в стиле генерации («заменит роспись, дороги, подписи,
  объекты; шаг — в историю») + после загрузки тост уже есть, его оставить.

### P0-3. Жёсткое удаление без второго шанса [П, М]

- `maps.ts:260`: `DELETE /:id` — всегда `{ ok: true }`, даже по несуществующему id.
  Клиент: один confirm — и карта с часами росписи исчезает навсегда, каскадом
  (привязки — каскадом, undo нет). Комментарий в коде упоминает «тост UndoDelete»,
  но в `MapsListPage`/`MapEditorPage` такого тоста нет — либо задумка не
  реализована, либо потеряна.
- Исправление (на выбор владельца): корзина/мягкое удаление **или** тост
  «Карта удалена → Восстановить» с окном ~10–15 с (данные держать в памяти
  клиента + серверный undelete-таймер — лишний механизм; проще корзина флагом).
  Минимум: `DELETE` по несуществующему id должен отдавать 404, а не `ok:true`.

## P1 — важно (второй эшелон)

### Дизайн-система

- **P1-1. `design_revision.md` §7 врёт про палитру [Д, К].** В §7 сказано
  «13 цветов», формулой «9 базовых + лава/кислота/яд + стена». В коде
  (`render.ts:11`, `MAP_TERRAIN_FILL`) уже **18**: добавились `stone/wood/earth/
  darkness/necro`. Документ объявил себя выигрывающим при расхождениях — значит,
  править документ (а не код): перечислить 18 + мотивы пакета B + решение про
  чистый чёрный тьмы.
- **P1-2. Обводка выбора 2 px против 1 px из §7 [Д].** §7: «Обводка выбора —
  **1 px** с отступом 2 px». Код (`render.ts:950, 982`): `lineWidth = 2` у
  выбранных дверей/ловушек. Либо код к 1 px, либо решение в документ.
- **P1-3. Полупиксельные штрихи 1.5 px [Д].** Ловушки/маркеры рисуются
  `lineWidth = 1.5` (`render.ts:971` и рядом). Инвариант §1.3: 1 px везде, без
  промежуточных. Для canvas есть резон (чёткость на 1×), но тогда это должно
  быть записанным исключением, а не молчаливым.
- **P1-4. Сырые шрифты в canvas мимо голосов и шкалы [Д, К].** Оверлей линейки
  (`MapEditorPage.tsx:1919`: `"12px Oswald"`), легенда PNG (`mapExport.ts:160–168`:
  `"16px/11px Oswald"`, `"12px sans-serif"`, `"700 10px monospace"`) — в обход
  `readCanvasFonts()` и шкалы кегля. Проверить, не ругается ли
  `check-type-scale.mjs` на карты (в `DESIGN.md` исключение дано только печатной
  шпаргалке); свести всё к `readCanvasFonts` + токенам.

### Безопасность и корректность (не P0, но рядом)

- **P1-5. Авторизация держится на одном глобальном гейте [К].** Запись режут
  только `apiRoleGate` (`playerAccess.ts:72` — игрокам разрешён лишь `GET /maps*`),
  внутри `maps.ts` проверки роли нет. Порядок монтирования в `index.ts:245,345`
  сейчас верный, но любая перестановка — и игроки получают запись. Добавить
  пояс-защиту в мутирующие роуты (`POST/PUT/DELETE`, включая `bindings`) —
  дёшево и независимо от тестов.
- **P1-6. Space перехват ломает клавиатурную доступность [К, П].**
  `MapEditorPage.tsx:1976`: глобальный `keydown` на `Space` делает
  `preventDefault` везде, кроме инпутов. Сфокусированная кнопка больше не
  активируется пробелом. Ограничить перехват: только когда фокус на canvas/
  body, а не на интерактивных элементах.
- **P1-7. Esc не закрывает панели объектов [П].** Esc сбрасывает линейку/стену/
  шейп (`:2075`), но открытые черновики подписей/дверей/ловушек/комнат не
  закрывает. Один Esc должен закрывать верхний слой (панель → замер → черновик
  линии) в предсказуемом порядке.

### Пользовательские «КАК ЭТО НЕТ?!»

- **P1-8. Данж и двери — только квадраты, а черновик по умолчанию — гексы [П, М].**
  `quickDraft` (`MapsListPage.tsx:237`) создаёт гексы; данж на гексах упирается в
  ошибку «Подземелье — только на квадратах», двери там же. Мастер-данженщик
  проходит путь «создал → открыл → облом». Исправление: на гексовой карте вкладку
  «Подземелье» дизейблить с объяснением + в модалке создания подсказку, что
  данжи — на квадратах (одна строка под радио).
- **P1-9. Нет панели истории undo [П].** Undo вслепую (уже в бэклоге `На_будущее.md`
  п.U2). Подтверждаем приоритет: после P0 — первым из удобств.
- **P1-10. Смены сетки нет в UI [П].** Сервер умеет смену сетки с `clearCells`
  (`maps.ts:177`), клиентская «Настройки» сетку вообще не показывает: «навсегда»
  означает «даже с очисткой нельзя». Либо добавить смену с двойным confirm, либо
  записать решение «смены нет вообще» и убрать мёртвую ветку сервера.
- **P1-11. Подпись `cell_lore` без валидации в UI [П].** Непарсящаяся строка
  («5 футов» — парсится; «пять футов» — молча нет) тихо лишает линейку метров.
  Подсветить формат прямо в «Настройках» (пример + живая проверка).
- **P1-12. Кнопки инструментов без видимых хоткеев [П].** Хоткеи живут только в
  `title`-тултипах; на кнопках (`:2819`, `:3020`) их не видно. Показать кегль
  хоткея на кнопке (мелкий суффикс моноширинным) + оставить шпаргалку доступной
  из тулбара (сейчас её вообще нет в UI — только разрозненные title).
- **P1-13. «Удалить» рядом с «Дублировать» [П].** Четыре кнопки шапки подряд,
  деструктивная — в одном ряду с нейтральными. Отбить danger-стилем и отступом.

### Мастер за столом и печать

- **P1-14. PNG-экспорт: нет привязки к бумаге [М].** Есть плотности 16–64 px/кл,
  но нет пресетов «А4/Letter при N мм на клетку» и помощника «боевая карта
  1 дюйм = 5 футов». Мастер считает сам. Добавить пресеты размера клетки в мм/
  дюймах + расчёт итога до экспорта.
- **P1-15. Координаты на экране выключены по умолчанию [М].** За столом ссылка
  «идёте в B12» требует координат на поле; дефолт выкл (в PNG — вкл, верно).
  Предложение: запоминать выбор (как панели) — уже запоминается через
  localStorage; тогда пункт снимается. Проверить, что персист работает, иначе —
  дефолт вкл.
- **P1-16. Тумана войны нет, показ — ссылкой [М].** Известное ограничение
  (`На_будущее.md` п.1): «Показать игрокам» = флаг + ссылка + «обновите раздел».
  Живой пуш — отдельный заход; здесь фиксируем как границу, а не как баг.
