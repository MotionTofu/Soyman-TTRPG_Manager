# Стены, проходы, панели, новые биомы/объекты — план

Дата: 2026-09-03. Источник: хотелки владельца + ответы (все «да» + палитра: тьма — чистый чёрный,
некро — тёмно-серая с черепом). Статус: в работе с Этапа A.

## Замороженные решения

1. **Стены линией красят террейн `wall`** (суперкавер по полилинии, один undo-шаг). Векторные
   сегменты-объекты — тяжелее (рендер каждый кадр, хит-тест distance-to-segment, blob v5, свой
   PNG/валидация) без надобности сейчас; модель данных их позже переживёт.
2. **Реки — оверлей-бит** как дороги (рендер: реки под дорогами, мост читается).
3. **Сундуки/алтари игрокам видны** (стрип не трогает; в PNG вида игрока — в легенде).
4. **Подпись — в «Объекты»**, линейка — отдельным замером в главном ряду.
5. **Палитра:** тьма `#000000` + бумажные звёзды (риск: сетка/координаты на чёрном — проверка глазами
   в Этапе H); некро тёмно-серая + упрощённый череп (круг + глаза). Числа — скриптом в Этапе B.

## Этапы

- **A. Данные: blob v4.** `markers: [{x,y,kind}]` (`chest|altar`, кап 300 — задел под NPC из M5),
  `rivers: string[]` (как `roads`). Парс v1–v3 совместим, битое — поштучно; сервер строго;
  стрип игрока не трогает; `translateMapError`; тесты; базовый рендер на поле + легенды
  (инструменты размещения — в F, генератор не ставит).
- **B. Шесть террейнов.** `stone/wood/earth` (полы), `darkness/necro` (биомы); fills + мотивы
  (камень — тесаные точки, дерево — планки, земля — редкая сыпь, тьма — звёзды, некро — череп);
  легенды; `MAP_TOOL_ORDER`; руки-only. Числа дейтеранопия/dLum до покраски.
- **C. Реки.** Мазок/ластик/пипетка зеркалят дороги; рендер шире + вода; легенда/PNG/превью.
- **D. Генератор.** Двери только в горлышках 1–2 (прогон коридора вдоль стены, концы заперты;
  сосед-комната — можно; парность на ширине 2 — существующей группировкой; `pickDoorKind`
  после фильтра, чтобы не съехала сид-раздача); обводка комнат по соседям-`wall`/краю карты,
  пропуск на рёбрах с дверями. Тест-инвариант по N сидам.
- **E. Линия стен + шейпы.** `wallMode dab|line`; полилиния (клики, дабл-клик/Esc/Enter — финиш),
  снеп к центрам / свободно; суперкавер → `wall`, один шаг. Шейп-прямоугольник (U): комната →
  модалка с ректом; террейн/оверлей/ластик/стена → применение на рект, один шаг; эллипс — заглушка
  «скоро»; тач — два тапа по углам. Общее drag-превью.
- **F. Панели + инструментарий.** Главный ряд (кисть/заливка/ластик/пипетка + размер + undo/redo +
  аккордеоны + статус) → табы Биомы / Поверхность / Объекты → контент. Объекты: выбор, дверь
  (клик — последний вид, ребро по месту клика), ловушка, сундук, алтарь, старт, финиш, подпись.
  Хоткеи + шпаргалка. Сюда переезжает wall-line из E.
- **G. Ховер футпринта.** `hoverCells` через `brushCells` для кистей 2/3 (и реки/дороги/ластика).
- **H. Ручной прогон** (панк + нуар, 390px, печать PNG, данж-сиды) — за владельцем.
