# Действия и переходы статического макета v1.1
[Обзор](index.html)

## Основной путь
Библиотека → генератор → новая карта → готовый данж → размещение из поиска → свойства токена → карточка сущности → вид игрока → экспорт.

Каждое действие ниже переключает **подготовленный экран**, не выполняет операцию продукта. Нажатия по самим стенам/полу и перетаскивание не реализованы. Параметры и результаты фиксированы для разбора композиции.

| Действие | Где находится | Состояние / результат |
|---|---|---|
| Открыть модуль | Внешний вход приложения, заменён шапкой макета | library; инструменты слева, поиск/мешок справа |
| Открыть карту | Превью в библиотеке | dungeon |
| Новая карта | Библиотека | empty |
| Начать рисовать | Empty state / rail «Комната» | room, форма/стена/привязка в строке параметров |
| Кисть / стена / дверь | Rail | brush / room / door с разными параметрами и маркером на карте |
| Объекты | Rail | assets, полка поверх нижней части карты |
| Слои | Rail | layers, окно слева на карте |
| Быстрое подземелье | Шапка / библиотека / пустой холст | generator, параметры + preview |
| Другой вариант | Генератор | тот же фиксированный пример; алгоритма нет |
| Создать карту | Генератор | generated, сообщение о новой карте; затем dungeon |
| Перенос существа | Результат поиска, + | drag, призрак скрытого токена и подсказка drop |
| Перенос локации | Мешок, + | bagdrag, маркер локации и подсказка |
| Разместить без drag | + на узком экране | narrow, правый блок закрыт; выбор точки и «Поставить здесь» → token |
| Выбрать токен | Токен на карте / rail | token, свойства поверх холста справа |
| Открыть источник | Свойства токена | preview, краткая карточка из библиотеки |
| Скрыть от игроков | Свойства токена | hidden |
| Показать игрокам | Свойства токена | отдельное подтверждение публикации имени/картинки; затем поясняющий результат |
| Удалить токен с карты | Свойства токена | dungeon; удаление только обозначено, исходная сущность не затрагивается |
| Вид игрока | Шапка | player, скрытые токены и инструменты мастера убраны |
| Экспорт | Шапка | export, PNG и правила видимости |
| Скачать / копия / исходный файл | Соответствующее окно | поясняющий результат; файлы не создаются |
| Вернуться к картам | Шапка / нижний rail | library; из saving/saveerror — leave |
| Закрыть вспомогательный экран | Крестик / Esc | dungeon; карточка источника возвращается к свойствам крестиком |

## Состояния для проверки
| Экран | Что проверяется |
|---|---|
| long | Длинные имена в поиске; перенос, отсутствие горизонтального скролла |
| missing | Нет портрета и недоступен источник; имя и положение сохраняются, связь можно выбрать заново |
| hidden | Скрытый токен, объяснение видимости и явная публикация |
| bagempty / searchnone / searchloading | Пустые и промежуточные состояния; панели сохраняют размеры |
| saving / saveerror | Статус сохранения, повтор и локальная копия |
| unsupported | Карта из более новой версии; без редактирования, исходный файл для мастера |
| conflict | Остановка сохранения при новой версии из другого окна; скачать свою копию, открыть актуальную, остаться |
| leave | Ошибка при выходе; остаться, повторить, скачать копию, явно выйти с потерей изменений |
| narrow / narrowsearch | Узкая компоновка, выбор через +, временное открытие/закрытие поиска и мешка |

Сохранение и конфликты соответствуют ADR-0004. В реализации «остаться» оставляет локальные изменения и конфликт, а «повторить» действительно повторяет сохранение; здесь это только переходы между статическими экранами. Неподдерживаемая версия не предлагается к принудительной перезаписи.
