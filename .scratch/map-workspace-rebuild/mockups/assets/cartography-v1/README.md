# Fantasy Cartography — набор v1

Создан 2026-09-30 по запросу пользователя. Встроенный image_gen, без CLI/API fallback. 17 отдельных PNG по 1254×1254 px: 3 поверхности, 9 элементов данжа, 4 региональных символа, 1 портрет. У 13 объектов проверена настоящая прозрачность, у 4 поверхностей/портрета — непрозрачность.

Назначение: отдельные повторяемые материалы и объекты для данжа и региональной карты SoyMan. Это набор для визуального макета и дальнейшей подготовки библиотеки редактора. Сам рабочий renderer не входит в эту задачу.

Стиль: рисованная фэнтезийная картография, уверенный тёмный контур, мелкая штриховка, тёплый камень/дерево, приглушённая зелень и вода. Панк-акценты остаются преимущественно в интерфейсе; мир читается в спокойной палитре. Данж — ортографический вид сверху. Региональные условные знаки — отдельная группа с небольшой картографической высотой.

Поверхности запрашиваются повторяемыми; фактическое качество стыков проверяется отдельно. Объекты запрашиваются с настоящей прозрачностью, без фона, подписи и рамки. Исходные PNG сохраняются без обработки alpha и без перезаписи предыдущих ассетов.

Точные промпты и результаты: [prompts.json](prompts.json), [manifest.json](manifest.json). Проверка размеров и прозрачности: [asset-qa.json](asset-qa.json). [Визуальный каталог](../../asset-catalog.html).

Оригиналы генератора скопированы в эту папку. Исходники не обрезались и не перекодировались. Для рамки показа используются пиксели с alpha ≥64 и небольшой запас: это убирает влияние практически невидимых следов на масштаб, сохраняя все оригинальные файлы. В автономных SVG-сценах оригинальные PNG встроены как data URI; библиотека по-прежнему содержит отдельные исходники.

Состояние для будущего рабочего набора: дополнительные направления/варианты стен и дверей, подготовка масок и привязок, доводка стыков повторяемых текстур, оптимизация упаковки/разрешений. PNG-ассеты уже существуют; поведение кистей, камер и placement не реализовано этим набором.
