# Самостоятельное рабочее пространство карт
Status: ready-for-agent
Execution: completed
Type: task
Depends on: 01, 11

[План](../plan.md) · [Спецификация](../spec.md)

## Задача
Добавить явный режим оболочки для карт по образцу существующего режима пульта, библиотеку карт и вход/выход. Убрать дублирующие внешние панели. Слева rail, справа локальное представление общих поиска и мешка. Существующие состояния и сервисы переиспользовать. Компоновку собирать по точному макету из тикета 11, после его проверки и учёта замечаний.

## Критерии готовности
Режим восстанавливается по URL; две панели заменены; поиск/мешок доступны одновременно; выход возвращает оболочку; 1366×768 без горизонтального скролла; звук и мешок не сбрасываются.

## Проверка
Сценарии прямого URL, reload и Back/Forward; вход из приложения и возврат; окно Electron и узкий экран.

## Границы

В этом тикете меняется оболочка, а V5 ядро и формат сохранения остаются текущими; V6, связанные токены и художественный renderer относятся к последующим тикетам.
