# Перенос из поиска и мешка на карту
Status: ready-for-human
Execution: complete
Type: task
Depends on: 03, 04

[План](../plan.md) · [Спецификация](../spec.md)

## Задача
Общий drag protocol использовать через проверяемый адаптер. Разрешать being/location и монстров compendium_entry (уточнение пользователя 2026-09-30). Добавить ghost, snap, одно undo-действие, получение доступного имени/портрета и fallback. Для touch/keyboard — Разместить → следующий клик/подтверждение. Свойства и entity preview показывать на холсте.

## Критерии готовности
Оба источника создают связанные токены; повторный drop разрешён; мешок сохраняет записи; источник остаётся целым; неверный drop/ошибка resolution не создают мусор; preview не выводит из модуля.

## Проверка
Размещение при offset/pan/zoom, snap и без него, square/hex, повторные IDs, undo/reload. Ошибочные и неподдерживаемые payloads; клавиатура; исчезнувший источник.

## Границы
Реализация разрешена пользователем «продолжим». Следовать spec.md и ADR-0004; сохранять параллельные изменения пользователя. Публичная проекция остаётся в тикете 09.
