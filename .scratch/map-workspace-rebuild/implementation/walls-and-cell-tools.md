# Ломаные стены и клеточные кисти — 2026-10-01

## Стены

Инструмент «Стена» создаёт слой `path` с именем «Стены» и одну линию `kind: wall` на завершённый контур. Узлы хранят только `position`, без ручек Безье; толщина — `width`, замыкание — `properties.closed`. Первая точка не дублируется в конце замкнутого контура. Документ V6 и формат обмена сохраняются.

Клик добавляет точку, Enter/двойной клик заканчивает открытую стену, клик по первой точке или кнопка «Замкнуть» закрывает контур. Esc отменяет черновик. Черновик не записывается в документ; завершённая стена — один шаг отмены. Пробел/средняя кнопка позволяют сдвинуть карту во время построения. Для квадратной сетки привязка ставит узлы на её пересечения.

Общий рендер использует `wall-masonry.webp`. Текстура каждого прямого сегмента обрезается его многоугольником. Соседние сегменты имеют общую границу стыка; на острых углах применяется срез вместо длинного шипа. Для открытых концов используются отдельные торцы из установленного парного листа `wall-masonry-end.webp`; замкнутые стены торцов не имеют. Старые клеточные стены остаются существующей геометрией, новое рисование не закрашивает клетки скалой.

«Выбор» двигает стену целиком и её точки. Свойства меняют толщину и замыкание, добавляют/удаляют точки; сглаживание для стен не предлагается.

## Поклеточный пол и ластик

Размер кисти — от 1 до 16 клеток по стороне (`settings.cellSize`); под курсором отображаются именно те клетки, которые изменит кисть. Быстрый штрих интерполируется без пропусков. На границе карты отпечаток обрезается.

Режим `settings.cellMode: area` выделяет рамку и обрабатывает её целиком при отпускании мыши. Отмена рамки не меняет документ; завершение — один шаг отмены.

Комнаты и замкнутые стены, выбранные «Выбором», можно заполнить или очистить кнопками «Залить выделенное» / «Стереть выделенное» в параметрах «Пола»/клеточного «Ластика». Меняется только выбранный клеточный слой пола; комнаты, стены и прочие слои сохраняются. Для фигур учитывается вхождение центра клетки, пересечения выбранных областей обрабатываются один раз. Очистка удаляет клеточные переопределения и возвращает материал слоя по умолчанию.

Масочный ластик сохраняет существующий радиус и поведение; новые клеточные режимы относятся к `terrain.representation: cells`.

## Проверки

Командные и жестовые тесты покрывают создание/замыкание, V6 round trip, редактирование узлов, отмену черновика, прямые/острые стыки, торцы, размер кисти, рамку, выбранные комнаты и замкнутые контуры, защиту слоёв. Проверка в браузере недоступна: встроенная вкладка не подключилась. Для ручной визуальной проверки подготовлен `walls-preview.html`, использующий настоящий общий рендер стен через локальный Vite.
