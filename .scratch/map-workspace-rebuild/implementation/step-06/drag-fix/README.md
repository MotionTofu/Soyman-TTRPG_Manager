# Исправление переноса существ и входа в редактор

Дата: 2026-09-30. [План](../../../plan.md) · [Тикет 05](../../../issues/05-entity-placement.md).

Пользователь сообщил, что существа из населения сеттингов и бестиария не переносятся через поиск или мешок при обычном открытии карты. Найдены две причины: обложка и создание карты открывали классический редактор без размещения токенов; адаптер нового редактора принимал being/location, но не монстров compendium_entry.

Обычный GM-клик, создание и быстрый черновик теперь открывают основной `/maps/:id/workspace`. Классический экран явно обозначен отдельной временной ссылкой для прежнего генератора и показа игрокам. На самом классическом экране есть переход в основной редактор с токенами. После первой записи V6 классическая ссылка исчезает; загрузка старой карты сама по себе не пишет документ. Маршрут просмотра игрока сохранён. Полное удаление прежней обвязки остаётся в тикете 10.

Бестиарий поддержан в canonical sourceRef, адаптере, серверном resolver и представлениях. Только compendium_entry с kind=monster и активной системой разрешается как источник. Прежние записи мешка без subtype разрешаются сервером; заклинания не становятся токенами. Монстр получает круг, портрет либо силуэт существа. Связь хранится по UID, повторное размещение создаёт независимый экземпляр; мешок не расходуется. Сохранённые токены продолжают работать при архивировании/удалении источника, новые недоступные источники отклоняются.

## Проверка

- **526 тестов клиента / 52 файла**: картографическая регрессия, workspace, маршруты, адаптер и размещение.
- **13 серверных V6 API тестов** на временной БД: monster/spell, UID/имя, save, архив системы, удаление источника, orphan refs, GM-only и закрытый player flow.
- **16 тестов shared map core / 3 файла**: канонизация, совместимость, портрет и detach бестиария.
- **12 браузерных групп**: обычный клик по обложке, настоящий drag существа населения из поиска/мешка, настоящий drag монстра из поиска и прежней записи мешка, карточка на холсте, сохранение/reload, undo/redo, размеры/поворот, панорамирование/масштаб/DPR, square/hex, отмена, недоступный источник и блокировка слоя. [Результат](browser-qa.json), [сценарий](check-drag.mjs). Runtime/React console errors: 0.
- Проверка типов клиента, сборка shared, Vite bundle и scoped lint изменённых адаптера/свойств/библиотеки прошли. Полный build со всеми style guards и native Electron не заявляется.

Браузер использует тестовые сущности и перехватывает API; сервер на рабочей БД не запускался. Ранее отмеченные ограничения шага 05 остаются: художественный рендер — 07–08, публичный V6 — 09, финальное переключение/Electron — 10.
