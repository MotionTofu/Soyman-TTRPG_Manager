# Базовый V6 редактор — тикет 04

Дата: 2026-09-30. Следующий шаг после оболочки и модели токенов. Существующие и параллельные изменения рабочей копии сохранены.

## Результат

В библиотеке карт у мастера появился пункт «Открыть новый редактор», маршрут `/maps/:id/workspace`. Весь документ V6 находится в состоянии редактора, истории и сохранения. Загрузка старой карты обновляет модель только в памяти; первая завершённая правка скрытой карты сохраняет V6 с capability 6 и expectedRevision. Старый маршрут остаётся для прежних карт до переключения в тикете 10; карточка уже сохранённой V6 карты ведёт в новый редактор.

- Ручной данж: кисть пола (камень, дерево, земля, вода), непрерывные стены, ластик, прямоугольные комнаты, двери двух ориентаций, подписи и локальные символы объектов.
- Выбор, перемещение комнаты/двери/подписи/объекта, изменение имени комнаты и подписи, поворота двери, размера/поворота объекта, удаление только размещения.
- Undo/redo: один штрих или drag — один шаг. Escape/pointer cancel возвращает состояние до жеста, не создаёт шаг; незавершённый жест приостанавливает запись. Переключение инструмента и уход завершают жест.
- Камера, fit, wheel zoom и Space/middle-button pan отделены от документа/истории/сохранения. ResizeObserver обновляет Canvas; проверен DPR 2. Показ сетки и snapping независимы.
- Окно слоёв поверх карты: активный слой, имя, порядок, плотность, скрытие, блокировка и создание. Скрытый/заблокированный активный слой не перенаправляет кисть на другой. Свойства тоже находятся над холстом; справа остаются общий поиск и мешок.
- Переиспользуются V5 геометрические операции через проверенный адаптер. Этот view никогда не сохраняется и не входит в историю. Токены и порядок items сохраняются, включая добавление/удаление соседних сущностей и перемещение слоёв; удаление слоя с токенами через адаптер запрещено. Коллизия ID с токеном отклоняется валидатором полного V6.
- Flush отправляет последние правки сразу и ждёт все последовательные записи. Ссылка и same-document Back/Forward ждут flush. При ошибке редактор остаётся открыт; доступны повтор и скачивание `/3` master backup. При конфликте revision записи прекращаются. Нативный уход из документа/перезагрузка использует beforeunload.
- Ранний POP listener подключён до BrowserRouter. Пока карта не требует защиты, он ничего не меняет; guard активен только на новом редакторе. Это сохраняет существующий router остальных страниц.
- Уже опубликованные старые карты открываются без редактирования: действие «Создать скрытую копию» делает private V6 копию, оставляя прежний показ. Пока публичная проекция V6 не готова, скрытые карты служат рабочими черновиками.
- Неподдерживаемый/повреждённый документ и сервер без revision не получают writer. Исходный документ можно скачать. Игрок не запрашивает мастерский документ нового редактора.
- Архивирование V6 в библиотеке, восстановление и отмена восстановления в архиве передают capability 6. Проверены сохранность документа/связей и рост revision при archive/restore.

## Границы

Это рабочая база нового редактора, а не готовая художественная замена. Используется проверенный текущий Canvas renderer; новые сгенерированные картографические PNG подключаются в 07–08. Стены пока клеточные. Кисть этой базы работает на клеточном terrain; редактирование mask/spline/scatter и полная библиотека ассетов продолжаются в 07.

Токены V6 сохраняются с геометрией и временно отображаются условными значками мастера. Размещение из поиска/мешка, разрешение имени/портрета и свойства токенов — следующий тикет 05. Публичная проекция, PNG/thumbnail, переносимые ассеты и показ V6 игрокам — 09; сервер остаётся закрытым для публичного V6. Новый редактор не меняет player_visible существующих карт при сохранении.

Нативный Electron/offline, полноценные touch/pinch сценарии и финальное переключение проверяются в 10. Browser Back после перезагрузки может быть переходом между документами: его защищает нативный beforeunload; same-document Back/Forward проверен отдельным guard. У уже опубликованной старой карты используется новая скрытая копия, чтобы не прервать текущий показ.
