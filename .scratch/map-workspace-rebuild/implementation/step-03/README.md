# Этап 3 — самостоятельная оболочка карт
Дата: 2026-09-30. Тикет 02 реализован на основе макета v1.1.

## Что работает
- URL `/maps` и `/maps/:id` включает режим карт только у мастера; библиотека, прямой вход, reload, Back/Forward и возврат в предыдущий раздел.
- Левая полоса 64 px (56 на узком экране) замещает навигацию. 20 новых векторных пиктограмм, рабочие V5 инструменты; длинный набор прокручивается, палитра и слои закреплены снизу.
- Правая колонка 272 px содержит настоящий поиск и общий мешок, независимо от свёрнутых модулей обычной оболочки. На экранах до 900 px — по кнопке или `/`, закрытие кнопкой, фоном или Escape с возвратом фокуса.
- Запрос поиска, мешок и звуковые сервисы продолжают жить при смене режима. Панель звука остаётся тем же DOM-элементом на SPA-переходах.
- Палитра и слои/свойства открываются по одному над холстом. ResizeObserver обновляет разрешение canvas при изменении его размеров.
- Скрытые панели пульта не скрывают интерфейс карт; их прежнее состояние восстанавливается при выходе.

## Проверки
- 475 тестов в 47 файлах: ядро/инструменты/история/камера карт, страница редактора, режимы оболочки, аудиоплеер и звуковой движок.
- TypeScript: успешно. Production bundle Vite: успешно; существующее предупреждение о крупных chunks.
- Oxlint изменённых файлов: ошибок нет; три прежних предупреждения зависимостей hooks в MapEditorPage сохраняются.
- [Браузерный отчёт](browser-qa.json): 11 снимков на 1366×768, 1920×1080, 820×900, 390×844; без горизонтальной прокрутки страницы и содержимого поиска/мешка. Проверены вход из приложения, возврат, прямой URL, reload, Back/Forward, сохранение запроса/мешка/общей раскладки, непрерывность DOM панели звука, Escape и `/`, прежние скрытые панели пульта.
- Весь API в браузерном стенде перехвачен тестовыми ответами. Рабочая БД не читалась и не изменялась. Контент на снимках явно тестовый.
- Общие барьеры дизайна репозитория пока падают: 237 нарушений кегля и 446 шага/обводки в существующих файлах. В новых файлах workspace нарушений нет; отчёты `type-scale.log`, `spacing.log`. Полная команда npm build поэтому не считается прошедшей.
- Нативное окно Electron вручную не запускалось: проверен Chromium/Edge, без новых зависимостей от desktop bridge. Проверка в реальном окне Electron остаётся в регрессии перед переключением (тикет 10).

## Границы этапа
Это рабочая компоновка существующего редактора, не завершённая замена всего редактора. Документ/сохранение остаются V5, исходная отрисовка и генератор сохраняются. Новые raster-ассеты из макета ещё не подключены к renderer; связанные токены и drop существ/локаций — следующие тикеты 03/05. Доступ игрока остаётся в обычной оболочке.

## Отличия от макета v1.1
- Нижняя звуковая панель занимает 52 px: рабочий холст на 1366 имеет 1030×576 вместо концептуальных 1030×640; внизу остаётся доступ к горячим клавишам. При скрытом пользователем плеере резерв пока сохраняется.
- До переработки контекстных параметров сохранены существующие меню и команды. На узком экране они занимают дополнительную строку 44 px.
- Свойства V5 пока собраны в одном выдвижном окне 284 px; разделение по типам объектов — тикет 04. Камера и реальные жесты требуют дальнейшего продуктового разбора.
- Макет v1.1 сохранён как исходная опора; эти отличия отмечены в его контракте, а не выданы за точное совпадение с концептом.

Дополнительно проверено взаимодействие с общим F4: скрытие и восстановление панелей не пересоздаёт звук, canvas занимает освобождённую ширину, затем полоса инструментов возвращается.


В библиотеке карт также исправлен меняющийся размер списка зависимостей useMemo при загрузке миниатюр: раньше React выдавал предупреждение на каждом открытии списка. Запросы миниатюр и их кэширование сохранены.
