# 02 — Номер и часть листа

**Blocked by:** —

**Status:** ready-for-agent

**Spec:** `../spec.md` — «Номер и часть листа»

**What to build:** Необязательные `number` и `part` у `WorkbookSheet` (`shared/src/workbooks.ts`): валидация, язычки и подвал `WorkbookBook` показывают `number` вместо порядкового, «Все листы» группируются по `part`, экспорт в Markdown пишет `## <number>. <title>`.

## Acceptance criteria

- [ ] Шаблон без `number`/`part` выглядит и экспортируется как прежде (тест)
- [ ] Лист без номера среди нумерованных («Как вести») не получает номера и не сдвигает остальные
- [ ] Слишком длинные или не строковые значения отклоняются валидацией
- [ ] Определения практических шаблонов не меняются — новые версии в базе не появляются
