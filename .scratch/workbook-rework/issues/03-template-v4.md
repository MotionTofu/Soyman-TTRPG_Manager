# 03 — Шаблон тетради кампании v4

**Blocked by:** 02

**Status:** ready-for-agent

**Spec:** `../spec.md` — «Шаблон v4», «Новые виды профиля»

**What to build:** `CAMPAIGN_WORKBOOK` `version: 4` целиком: вход «Как вести» и листы 1–26 по таблице спеки, тексты и подсказки — из листов курса. Новые виды профиля объявлены в `WORKBOOK_PROFILE_KINDS`; пока их вид не сделан (задачи 04–07), `WorkbookProfile` показывает строку «Этот раздел покажет данные кампании». Лист `activity` — своё определение у кампании с ключами v2 (`lines`, `intersections`, `pressure` + новые графы карточки процесса); `ADVENTURE_WORKBOOK` не меняется.

Работать в worktree на копии базы (`CONFIG_DIR`): каждое изменение определения регистрирует новую версию, а dev-сервер основной копии мигрирует живую базу. В основную копию шаблон попадает один раз, готовым.

## Acceptance criteria

- [ ] `validateWorkbookTemplate` проходит; ключи листов и граф постоянные латиницей, уникальны (тест)
- [ ] Номера и названия листов 1–26 совпадают с курсом; части — по плану курса §4
- [ ] `registerPracticalTemplate` для `oneshot-design` и `setting-design` возвращает прежний id (тест)
- [ ] Обновление v3 → v4 на копии базы: `activity/lines` переезжает сам («Взять планы в это проведение» работает), прочие ответы — в сопоставлении и «Прежних графах», ничего не потеряно
- [ ] Колонки «Статус» / «Кому известно» в таблицах листов 5, 11, 22 — выбор `У / П / Ч`, `М / Г / И / В`
- [ ] Новая кампания получает v4; существующие тетради остаются на своей версии
