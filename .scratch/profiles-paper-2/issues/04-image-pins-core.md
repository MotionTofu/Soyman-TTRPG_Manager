# 04 — Общий компонент «картинка + пины»

**Blocked by:** None

**Status:** done

**What to build:** Вынести из `LocationMap.tsx` ядро (картинка, зум/панорама, пины, замок, колонка пинов, «Не на …») в компонент, не знающий о месте.
