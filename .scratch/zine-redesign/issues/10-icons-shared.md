# 10 — Иконки: общие компоненты и списки

**Blocked by:** 08

**Status:** done

**What to build:**

Разделы ресурсов, компендиум, главы, связи, трекер инициативы, карта локаций и граф связей переходят на общий набор иконок. Треугольники раскрытия и крестики закрытия перестают быть символами из шрифта.

## Acceptance criteria

- [ ] В разделах ресурсов, компендиуме, главах, связях, трекере инициативы, карте и графе связей не осталось эмодзи-иконок
- [ ] Маркеры раскрытия и сворачивания нарисованы иконкой-шевроном единого вида во всех местах
- [ ] Кнопки «закрыть», «редактировать», «удалить» выглядят одинаково во всех перечисленных разделах
- [ ] npx tsc --noEmit и npm run build проходят чисто
