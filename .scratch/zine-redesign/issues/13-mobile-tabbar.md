# 13 — Мобильная панель: центральная кнопка и быстрый доступ

**Blocked by:** 08, 12

**Status:** ready-for-agent

**What to build:**

Нижняя панель на телефоне получает приподнятую круглую кнопку по центру (§7.1 диздока). Она открывает быстрый доступ: закреплённые страницы (до семи, тот же механизм, что на десктопе), возможность закрепить текущую и контекстное действие экрана.

Раскладка становится симметричной. У игрока список персонажей переезжает в «Кабинет», освобождая слот.

## Acceptance criteria

- [ ] Центральная круглая кнопка приподнята над панелью, залита акцентом, вокруг неё лучевой ореол; в режиме Neon добавляется свечение
- [ ] Нажатие на центральную кнопку открывает быстрый доступ: закреплённые страницы, «закрепить текущую» и контекстное действие текущего экрана
- [ ] Ограничение в семь закреплённых страниц соблюдается; закрепление с мобильного видно и на десктопе
- [ ] Раскладка симметрична: у мастера два слота, центр, два слота; у игрока — один, центр, один
- [ ] Список персонажей игрока доступен в «Кабинете»; отдельного пункта нижней панели у него больше нет
- [ ] Панель учитывает безопасную зону снизу; нажатие даёт короткий отклик уменьшением
- [ ] Проверено вживую на мобильной ширине 375×812 в обеих ролях
- [ ] npx tsc --noEmit и npm run build проходят чисто
