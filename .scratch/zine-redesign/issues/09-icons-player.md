# 09 — Иконки: плеер и музыка

**Blocked by:** 08

**Status:** ready-for-agent

**What to build:**

Аудио-плеер — сигнатурный компонент этого дизайна (§«Audio player» диздока и первый референс). Его транспорт перестаёт быть плотным рядом эмодзи и становится спокойным набором штриховых иконок; то же — на странице «Сейчас играет», в разделе музыки и в плейлистах.

## Acceptance criteria

- [ ] Транспорт плеера (предыдущий, пуск, пауза, следующий, перемешать, повтор трека, повтор плейлиста, громкость, плейлист, стоп) нарисован иконками из набора
- [ ] Страница «Сейчас играет», раздел музыки и списки плейлистов не содержат эмодзи-иконок
- [ ] Полоса плеера остаётся спокойной: второстепенные органы управления не теснят название трека
- [ ] Иконки читаются на тёмной полосе плеера во всех трёх зинных режимах
- [ ] npx tsc --noEmit и npm run build проходят чисто
