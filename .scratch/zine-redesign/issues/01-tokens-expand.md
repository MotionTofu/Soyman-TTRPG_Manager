# 01 — Токены: словарь диздока и шкалы (расширение)

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

**What to build:**

Приложение получает единый набор переменных из диздока (§3.1, §4.2, §6.2), не меняя внешний вид ни одной существующей темы. Это шаг «expand» в expand–contract: новые имена появляются рядом со старыми, старые становятся алиасами, поэтому ничего не ломается ни в одном промежуточном состоянии.

Движок тем остаётся один — существующий. Механизм data-skin не вводится.

## Acceptance criteria

- [ ] Генератор тем выдаёт --paper, --paper-2, --ink, --ink-2, --muted, --accent, --accent-2, --surface, --on-surface, --line, --glow
- [ ] Прежние имена (--bg, --bg-panel, --bg-elevated, --text, --text-bright, --text-dim, --border) продолжают работать как алиасы на новые
- [ ] Добавлены типографические переменные: --fs-hero, --fs-h1, --fs-h2, --fs-h3, --fs-body, --fs-meta, --fs-micro, --fs-stat
- [ ] Добавлена шкала отступов --sp-1…--sp-8 и переменные движения (--ease и три длительности)
- [ ] Все пять существующих тем визуально не изменились: переключение по очереди не даёт видимых отличий от текущего состояния
- [ ] npx tsc --noEmit и npm run build в client/ проходят чисто
