# 04 — Типографика: три голоса и шкала

**Blocked by:** 01

**Status:** done

**What to build:**

Текст в приложении получает иерархию из §4 диздока: тяжёлый сжатый гротеск для заголовков и названий, узкий гротеск для интерфейсных подписей, моноширинный — для чисел, дат, статов и метаданных. Между соседними уровнями иерархии видна разница, а не полутон.

Два отступления от буквы диздока, согласованные с пользователем: длинная проза набирается пропорциональным шрифтом (не моноширинным), а капс применяется к служебному тексту, но не к именам сущностей.

## Acceptance criteria

- [ ] Подключены три гарнитуры: Display (сжатый тяжёлый гротеск), UI (узкий гротеск), Mono; Hand — опционально
- [ ] h1–h4 используют шкалу --fs-* и Display/UI-гарнитуры согласно §4.1
- [ ] Числа, даты, статы, счётчики и метаданные набраны Mono
- [ ] Длинные тексты (лор-статьи локаций и существ, задумки и итоги сессий, предыстории персонажей, описания заклинаний) набраны пропорциональным шрифтом и читаются комфортно
- [ ] Капс применён к служебным заголовкам, лейблам, бейджам и кнопкам; имена кампаний, персонажей, локаций и существ отображаются обычным регистром
- [ ] Инлайновые fontSize/fontFamily в компонентах заменены на шкалу; в index.css не осталось несистемных размеров вне явно обоснованных мест
- [ ] npx tsc --noEmit и npm run build проходят чисто
