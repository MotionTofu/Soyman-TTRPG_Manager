# 15 — Перевёрстка: персонаж и сессия

**Blocked by:** 12, 14

**Status:** done

**What to build:**

Оставшиеся два экрана из §11.6. Карточка персонажа получает статы на костях и плотную сетку без вложенных рамок; страница сессии — ритм «шапка → вкладки → плотные списки», пригодный для работы за столом.

## Acceptance criteria

- [ ] Карточка персонажа: имя и мета в шапке, ряд статов на костях, дальше плотные секции без вложенных рамок
- [ ] Страница сессии читается за столом: крупное сверху, плотные списки ниже, ничего не требует горизонтальной прокрутки
- [ ] На мобильной ширине оба экрана остаются одноколоночными и не переполняются по горизонтали
- [ ] Полноэкранный статблок на телефоне сохранил прижатые к краям поля и липкую шапку
- [ ] Экраны проверены вживую на десктопной и мобильной ширине
- [ ] npx tsc --noEmit и npm run build проходят чисто
