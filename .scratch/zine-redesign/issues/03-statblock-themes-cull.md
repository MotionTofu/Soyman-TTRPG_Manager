# 03 — Темы статблоков: чистка до трёх

**Blocked by:** 01

**Status:** ready-for-agent

**What to build:**

Выбор темы статблока сокращается до трёх вариантов: «Зин» (новая, становится базовой), «Соевый Нуар» и «Аберрантный». Группа «По типам существ ДнД» и авто-подбор темы по типу существа уходят вместе с ней.

Данные не мигрируются: содержимое статблоков, их порядок и привязки не затрагиваются. Статблок, у которого в базе записана исчезнувшая тема, рендерится базовым (зинным) видом — это ожидаемое следствие решения, а не поломка. Откат — вернуть удалённые записи и их CSS.

## Acceptance criteria

- [ ] Селектор темы статблока предлагает ровно три варианта: Зин, Соевый Нуар, Аберрантный
- [ ] Зинная тема статблока задана по мотивам §3.1 и §6.3 диздока и является базовой
- [ ] Группа «По типам существ ДнД» удалена из селектора
- [ ] Авто-подбор темы при смене типа существа удалён; смена типа существа больше не трогает поле темы
- [ ] Статблок с удалённой темой в базе открывается и рендерится базовым видом, его поля и содержимое не изменились
- [ ] npx tsc --noEmit и npm run build проходят чисто
