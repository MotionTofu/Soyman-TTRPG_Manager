# 14 — Перевёрстка: главная и список кампаний

**Blocked by:** 04, 05, 06, 07

**Status:** ready-for-agent

**What to build:**

Первые два экрана из §11.6 диздока приводятся к его ритму: одно крупное, ряд среднего, плотный список мелкого. Заголовки секций получают единый «печатный» паттерн — иконка, капс-заголовок, ссылка «все →» справа.

## Acceptance criteria

- [ ] Главная построена по ритму «герой → плитки → плотный список»; правый рельс — стопка узких виджетов
- [ ] Список кампаний использует плитки-обложки: изображение, поверх снизу затемнение и название, под ним строка меты
- [ ] Заголовки секций единообразны: иконка, капс-заголовок, ссылка «все →» справа
- [ ] Внешние поля щедрые, внутренние компактные; между секциями крупный интервал — по шкале отступов
- [ ] Календарь и карандашные пометки на нём сохранены и вписаны в новый ритм
- [ ] Экраны проверены вживую на десктопной и мобильной ширине
- [ ] npx tsc --noEmit и npm run build проходят чисто
