# 11 — Иконки: статблоки и категории ресурсов

**Blocked by:** 08

**Status:** done

**What to build:**

Формы персонажа и существа — самые плотные экраны в приложении — переходят на общий набор. Категории ресурсов перестают хранить эмодзи прямо в данных и начинают ссылаться на иконки набора.

## Acceptance criteria

- [ ] В формах персонажа и существа не осталось эмодзи-иконок
- [ ] Категории ресурсов ссылаются на ключи иконок, а не хранят эмодзи в данных; списки ресурсов отображают нарисованные иконки
- [ ] Смена типа существа и переключение вкладок статблока не ломают отображение иконок
- [ ] npx tsc --noEmit и npm run build проходят чисто
