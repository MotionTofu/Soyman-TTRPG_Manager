# 12 — Числа на костях

**Blocked by:** 01, 07

**Status:** ready-for-agent

**What to build:**

Числовые характеристики перестают жить в квадратных плитках и ложатся на силуэты костей — приём из §6.5 диздока и второго референса. Цвет кости кодирует смысл (активная, обычная, недоступная), а не украшает.

Существующий виджет характеристик и спасбросков переводится на этот компонент, а не дублирует его.

## Acceptance criteria

- [ ] Есть переиспользуемый компонент кости со значением, подписью, видом (d20/d8/d6) и состоянием
- [ ] Силуэт — векторный; число набрано Display-гарнитурой по центру; подпись — микро-капсом под костью, не внутри
- [ ] Заполненные и контурные кости не смешиваются в одном ряду
- [ ] Виджет характеристик и спасбросков персонажа использует этот компонент; переключение характеристика/спасбросок по нажатию продолжает работать
- [ ] Ряд костей корректно раскладывается на мобильной ширине
- [ ] npx tsc --noEmit и npm run build проходят чисто
