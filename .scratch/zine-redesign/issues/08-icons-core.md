# 08 — Иконки: набор и оболочка приложения

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

**What to build:**

Интерфейс перестаёт рябить разноцветными эмодзи, которые к тому же по-разному выглядят на разных системах. Появляется единый штриховой набор в духе §8 диздока, и на него переводится оболочка приложения — шапка, боковое меню, панель поиска, плавающий навигационный виджет.

Сторонние библиотеки иконок не подключаются: расширяется набор, который в проекте уже есть.

## Acceptance criteria

- [ ] Набор иконок расширен до покрытия общих действий: закрыть, редактировать, удалить, поиск, меню, раскрытие (шеврон), ссылка, глаз, папка, галочка, загрузка, кость, переход
- [ ] Иконки штриховые, толщина линии 1.75–2, размеры 20 и 24, линия слегка неровная
- [ ] Иконки наследуют цвет текста и корректно перекрашиваются при смене темы
- [ ] В шапке, боковом меню, панели поиска и навигационном виджете не осталось эмодзи-иконок
- [ ] Стрелки внутри предложений (например «Настройки → Внешний вид») остались текстом, а не стали иконками
- [ ] npx tsc --noEmit и npm run build проходят чисто
