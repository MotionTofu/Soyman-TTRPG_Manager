# 06 — Цвет: три цвета и ни одного лишнего

**Blocked by:** 01, 05

**Status:** ready-for-agent

**What to build:**

Переключение темы прокрашивает весь интерфейс, а не половину: цвета перестают быть вписанными в стили намертво. Метки типов сущностей перестают быть радугой из одиннадцати оттенков и становятся «печатными» монохромными метками — тип и так подписан словом.

## Acceptance criteria

- [ ] Цветовые литералы в общих стилях заменены на переменные темы; исключение — блок значений по умолчанию и печатная вёрстка шпаргалок
- [ ] Метки типов сущностей монохромные: обводка и текст чернилами, без индивидуальных цветов
- [ ] Красный используется только для активного, выбранного и опасного; на типовом экране акцент занимает заметно меньше пятой части площади
- [ ] Оттенки получаются прозрачностью базовых переменных, новых hex не добавлено
- [ ] Инлайновый цвет в компоненте главной страницы игрока переведён на переменную
- [ ] Переключение всех пяти тем не оставляет блоков, застрявших в чужой палитре
- [ ] npx tsc --noEmit и npm run build проходят чисто
