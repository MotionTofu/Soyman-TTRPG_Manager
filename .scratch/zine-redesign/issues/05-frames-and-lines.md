# 05 — Рамки и линии: одна рамка на регион

**Blocked by:** 01

**Status:** ready-for-agent

**What to build:**

Исчезает «рамка в рамке», из-за которой сейчас теряется место на экране: вложенный обрамлённый блок наследует рамку родителя вместо того, чтобы рисовать свою. Линии становятся той толщины, которую задаёт тема, а не захардкоженного пикселя. Скруглений в системе нет — кроме аватаров, круглой кнопки таб-бара и бейджей-капсул.

## Acceptance criteria

- [ ] Ни на одном экране нет блока с собственной рамкой и фоном внутри уже обрамлённого блока — проверено на профиле кампании, профиле персонажа, странице сессии и в статблоках
- [ ] Правило одной рамки покрывает не только вложенные карточки, но и строки сущностей, блоки статблоков, плитки характеристик, уровни заклинаний, уведомления и легенды карты и графа
- [ ] Толщина линий берётся из темы, а не из захардкоженного 1px
- [ ] Радиусы: 0 или 2px; круглыми остались только аватары и центральная кнопка таб-бара, капсульными — бейджи
- [ ] Экономия места видна: на профиле кампании на мобильной ширине помещается больше содержимого, чем до изменения
- [ ] npx tsc --noEmit и npm run build проходят чисто
