# 02 — Состав тем приложения: три зинных режима вместо пятнадцати

**Blocked by:** 01

**Status:** done

**What to build:**

Пользователь видит в «Настройки → Внешний вид» короткий осмысленный список тем вместо полутора десятков. Появляются три режима из диздока — «Зин» (бумага/чернила/красный, дефолт), «Riot» (инверсия: чёрный лист) и «Neon» (кислота) — и остаются две ранее выбранные пользователем темы.

Удаление безопасно: поиск темы по id откатывается на первую тему, если сохранённый id исчез.

## Acceptance criteria

- [ ] Список тем приложения содержит ровно: Зин, Riot, Neon, Соевый Нуар, Аберрантный
- [ ] Зин — тема по умолчанию для нового пользователя
- [ ] Riot и Neon заданы значениями из §3.1 диздока (включая --glow у Neon)
- [ ] Пользователь, у которого в localStorage сохранена удалённая тема, открывает приложение без ошибки и видит тему по умолчанию
- [ ] Переключение между всеми пятью темами не оставляет непрокрашенных блоков на главной, в кампании и в настройках
- [ ] npx tsc --noEmit и npm run build проходят чисто
