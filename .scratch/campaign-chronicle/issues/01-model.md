# 01 — Модель: профиль события кампании, сессии, видимость, цвет точки цикла

**Blocked by:** 00 (макет принят владельцем)

**Status:** ready-for-human

**Spec:** `../spec.md` — «Модель», «Цвет» (Q12, только данные), «Бэклог»

**What to build:**

- Миграции в **конец** `migrateDatabase` (`server/src/db/db.ts`), ALTER на
  каждую колонку с проверкой `columnExists`, парная правка `schema.sql`:
  - `campaign_calendar_events.visible_to_players INTEGER NOT NULL DEFAULT 0`,
    `campaign_calendar_events.player_text TEXT NOT NULL DEFAULT ''`;
  - `setting_cycle_points.color TEXT` (ключ палитры, `NULL` — чередование).
- Маршруты событий кампании (`server/src/routes/campaigns.ts`): читать и
  писать новые поля; одиночное чтение события кампании для профиля (как
  `GET /settings/calendar-events/:eventId`).
- Связь «сессия → событие» в `generic_links` (своя секция, оба вида
  событий); чтение «сессии события» для профиля и строки (номер сессии,
  `sessionLabel`), «события сессии» — для «Итогов».
- `EventDetailPage` открывает и событие кампании: те же блоки, `LinkDropZone`
  с `campaign_event`, плюс «Видно игрокам», «Текст для игроков» и «Сессии».
  Маршрут профиля события кампании — на усмотрение исполнителя; строка
  кампании получает `href` на него.
- `playerContent.ts`: события кампании с `visible_to_players = 1` в
  `chronicleEvents` (с `player_text`); читалка игрока показывает их вместе с
  событиями сеттинга (Q19). Выдачи `grants` не расширять.
- Палитра цветов точек цикла — список ключей и тонов скина в одном месте
  (клиент), сервер хранит только ключ; неизвестный ключ — 400.
- Строки бэклога (спека, «Бэклог»).
