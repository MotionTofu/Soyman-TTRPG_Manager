# 07 — Деньги: архив отменённых и «Сверх сессий»

**Blocked by:** 03

**Status:** done

**What to build:** «Не состоялась» — в архив с подписью про оплату; миграция уносит отменённые в архив; заработок считает суммы существующих сессий и «Сверх сессий»; долг — по сыгранным не архивным; удаление из архива с деньгами предлагает перенос.

## Acceptance criteria

- [x] Нумерация сессий без счёта отменённых
- [x] Заработок кампании и «Главной» совпадают с правилом
- [x] Перенос при удалении — только по выбору Мастера
- [x] Миграция — в конец `migrateDatabase`

## Сделано (2026-10-02)

- «Не состоялась» в окне итога уносит сессию в архив (`DELETE /sessions/:id`), подпись: «Если есть какая-то оплата — она будет считаться до удаления из архива». Миграция (с таблицей `campaign_extra_payments`) уносит уже отменённые в архив; нумерация архивные и так не считает.
- Заработок (`campaignEarnings`, `totalEarnings`) — внесённое за любую существующую сессию плюс «Сверх сессий»; долг — как был, по сыгранным не архивным.
- «Сверх сессий»: `campaign_extra_payments`, `/campaigns/:id/extra-payments`; в свёртке «Оплата» — строки и форма.
- «Архив»: удаление сессии с деньгами спрашивает «Перенести и удалить» / «Удалить вместе с деньгами» (`GET /sessions/:id/paid`, `POST /sessions/:id/paid-to-extra` — строка на игрока, с датой сессии). Массовое удаление из архива переноса не предлагает.
