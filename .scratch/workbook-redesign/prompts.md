## Тетрадь-разворот

Use case: ui-mockup. Create ONE polished, convincingly usable desktop product design concept image for SoyMan, a Russian tabletop RPG campaign manager. Landscape 1536x1024. This is an application interface concept, not a photograph, not a wireframe, not a promotional poster. Show real readable typography and realistic restrained controls.

Visual language taken from SoyMan_1shot: tactile warm ivory paper #ece5d4, near-black printing ink #171717, acid-yellow #F3FF3A marker accents, small punk-magenta #FF3E91 accents. DIY fantasy punk zine comic style. Ink scratches, light halftone, paper tab edges, tiny fantasy marginal pencil drawings restricted to margins. Clear normal sans-serif reading text, expressive bold condensed display headings only for titles. Decoration surrounds the information, never covers text. Quiet writing surfaces, plenty of white space, comfortable large text, minimal thin lines. Avoid a dashboard, dense spreadsheet, big empty input boxes, repeated thick nested rectangular borders, tiny text, excessive stickers, glossy 3D, dramatic perspective, glows and neon gradients.

Workbook is universal, the sample lesson is "Точка входа". Name of this specific notebook "Мой ваншот". Scope label "Вся полка · 12 книг". Small saved state "Сохранено". Bookmarks should protrude from notebook edges as real chapter tabs, with a few legible labels "Замысел", "Герои", "Сцены", "Финал"; current tab "Герои". Short answers look like compact notebook lines with the saved answer in normal reading typography; longer answers are 3–4 lines which can grow when typing. Use at most 3–4 questions per page. No static tall empty textarea stacks. Sample copy "Почему герои здесь?", answer "На праздник в городе приехали старые друзья.", "Что заставит действовать?", answer "Во время праздника исчезает хранитель маяка.", "Что они могут потерять?", answer "Доверие города и единственную дорогу домой." Bottom navigation "← Назад" and "Далее →", small spread/page number.

Top-level workspace controls should be small and clear: "Внутри приложения" and "Отдельное окно", collapse icon, close icon. Opening is the primary action wherever a linked workbook launcher is shown. "Отвязать" must never be a prominent button: hide this in an ellipsis management menu. Link-to-shelf controls are supplementary, not repeatedly present on every question. Never show global SoyMan navigation inside a separate workbook window. All Cyrillic exact and legible.
