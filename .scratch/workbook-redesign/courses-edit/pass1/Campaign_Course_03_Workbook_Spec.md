# Campaign Workbook
## Рабочая тетрадь курса по созданию и ведению кампаний

> Один курс → одна живая модель кампании, способная обновляться после каждой сессии.

Главная формула:

```text
PROMISE
→ TABLE
→ PCs
→ PERSISTENT STATE
→ WORLD
→ FACTIONS
→ THREADS
→ INFORMATION
→ TIME
→ REWARDS
→ SESSION
→ PREP
→ SCENE
→ ADJUDICATION
→ SOCIAL PLAY
→ IMPROVISATION
→ PACING
→ SESSION DELTA
→ HEALTH
→ ENDGAME
```

## Правила Workbook

- Не записывать будущие действия PC как факты.
- Разделять текущее состояние, предположения мастера и будущие возможности.
- После каждой сессии обновлять только то, что действительно изменилось.
- Любой шаблон должен быть полезен за столом или при prep; если нет — сократить.
- Информация имеет уровни видимости: GM-only / PC-known / player-known / public / rumor.
- Существенные импровизированные факты после сессии либо канонизируются, либо явно помечаются provisional.
- У каждой долгой нити должен быть владелец состояния: фронт, фракция, PC goal, project или открытый вопрос.


## Нормативные формы

Синхронизировано с `Campaign_Course_Workbook.md` и `glossary.md` 0.3. Тетрадь — рабочая версия. Ниже перечислены все поля, варианты и колонки её листов; подписи сохранены вместе с каноническими именами. Ссылки «→» обозначают источник, а не повторный ввод.

Статус факта: черновик · предварительно · канон · спорно · заменено · отвергнуто. Только в этой кампании: да / нет — отдельное поле. Видно игрокам: да / нет; достоверность: известно / слух / спорно. CURRENT / HYPOTHESIS / POSSIBLE / ARCHIVED — отдельная ось состояния и прогноза.
