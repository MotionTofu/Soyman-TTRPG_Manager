# Как пользоваться Workbook

Эта тетрадь ведёт один ваншот через весь курс. Заполняйте её не как литературный синопсис, а как рабочую модель: коротко, проверяемо и с упором на решения игроков.

> **ГЛАВНОЕ ПРАВИЛО**
> Не записывайте, что игроки «должны сделать». Записывайте состояние мира, доступную информацию, силы, давление, цены решений и возможные изменения ситуации.


## РАБОЧИЕ ПРИНЦИПЫ

- [ ] Один Workbook = один ваншот.
- [ ] Критическую информацию дублируйте несколькими путями, а не одним обязательным броском.
- [ ] Не превращайте заготовленные последствия в обязательные события: это пространство возможностей, а не сценарный поезд.
- [ ] Любой повторяемый шаблон можно копировать столько раз, сколько требуется конкретному ваншоту.
- [ ] После плейтеста исправляйте не «всё, что не понравилось», а конкретные места, где модель не дала нужного игрового эффекта.

## СПИСОК ОТКРОВЕНИЙ (ТАЙНЫ)

Тип сведений — отдельная ось, не статус факта. Для каждого откровения: видно игрокам: да / нет; достоверность: известно / слух / спорно.

*Типы не взаимозаменяемы: факт — состояние мира; улика — наблюдение, указывающее на что-то ещё; вывод — интерпретация; секрет — скрытый факт; слух — переданное утверждение неизвестной надёжности; гипотеза — рабочее объяснение; ложное предположение — неверная модель, которую игроки могут проверить.*

# Приложение A. Атлас двигателей ваншота

Это не жанры и не готовые сюжеты. Это типичные двигатели активности — то, что заставляет сценарий производить решения. Их можно смешивать.


## ДВИГАТЕЛИ

| Тип | Что двигает игру | Главный риск проектирования |
| --- | --- | --- |
| Расследование | информация → гипотеза → проверка → новое откровение | единственная улика / единственный правильный вывод |
| Ограбление | цель → препятствия → план → осложнения | автор заранее пишет «правильный план» |
| Выживание | давление → истощение → приоритеты → цена | ресурсный учёт без значимых решений |
| Хоррор | неизвестность → понимание → цена контакта | слишком долго скрывать всё важное |
| Социальная интрига | желания → отношения → рычаги → смена союзов | NPC существуют только для экспозиции |
| Осада / оборона | угроза → подготовка → удары → удержание / прорыв | все решения сводятся к бою |
| Побег / преследование | давление времени → препятствия → сокращение возможностей | линейный коридор без развилок |
| Экспедиция | неизвестное пространство → риск → открытия → выбор маршрута | много красивых мест без функции |
| Инфильтрация / данж | пространство → маршрут → ресурсы → последствия шума / риска | каждая дверь ведёт к одному и тому же |
| Катастрофа | ухудшение состояния → приоритеты → спасение части ценного | катастрофа как декорация, не меняющая решений |

> **КАК ПОЛЬЗОВАТЬСЯ АТЛАСОМ**
> Выберите один доминирующий двигатель и, при желании, один вторичный. Если вы не можете объяснить, какие решения производит выбранный двигатель, вы пока выбрали эстетику, а не структуру.
