# Campaign Workbook
## Рабочая тетрадь курса по созданию и ведению кампаний

> Один курс → одна живая модель кампании, способная обновляться после каждой сессии.

Главная формула:

```text
PROMISE
→ TABLE
→ PCs
→ PERSISTENT STATE
→ WORLD
→ FACTIONS
→ THREADS
→ INFORMATION
→ TIME
→ REWARDS
→ SESSION
→ PREP
→ SCENE
→ ADJUDICATION
→ SOCIAL PLAY
→ IMPROVISATION
→ PACING
→ SESSION DELTA
→ HEALTH
→ ENDGAME
```

## Правила Workbook

- Не записывать будущие действия PC как факты.
- Разделять текущее состояние, предположения мастера и будущие возможности.
- После каждой сессии обновлять только то, что действительно изменилось.
- Любой шаблон должен быть полезен за столом или при prep; если нет — сократить.
- Видимость: видно игрокам — да / нет; достоверность — известно / слух / спорно. Статус факта: черновик / предварительно / канон / спорно / заменено / отвергнуто.
- Существенные импровизированные факты после сессии либо канонизируются, либо явно помечаются provisional.
- У каждой долгой нити должен быть владелец состояния: фронт, фракция, PC goal, project или открытый вопрос.

# Мини-пакет мастера для каждой сессии

Сводка собирается из листов 4–9, 15, 18 и журнала событий. В активном интерфейсе держать только:

1. текущее состояние;
2. 3–5 active forces;
3. 3–7 open threads;
4. ближайшие clocks/windows;
5. critical revelations;
6. current NPC leverage;
7. player intents;
8. session notes + quick capture.

Всё остальное должно быть доступно по запросу, но не загромождать рабочую поверхность.
