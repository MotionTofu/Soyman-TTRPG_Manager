# Шаг 2. Формат тетради из Markdown — 2026-10-01

## Сделано

- `shared/src/workbookMarkdown.ts`: разбор Markdown курса в модель листов/граф Codex.
  - Понимает три диалекта курсов:
    - ваншот: таблицы, «Запись», линии;
    - кампания: формы в ```text;
    - сеттинг: линии, нумерованные пункты, □.
  - На трёх настоящих курсах:
    | Курс | Листов | Граф |
    | --- | --- | --- |
    | ваншот | 17 | 248 |
    | кампания | 27 | 215 |
    | сеттинг | 36 | 282 |
  - Все три проходят проверку модели.
  - Пометки комментариями: `шаблон/версия`, `карточка[: тип]`, `поле: force.x`, `тип: страница|картинка`, `{#key}`.
- Модель (`shared/src/workbooks.ts`):
  - новые типы: строка, страница, картинка, заголовок, пояснение;
  - таблица с заданными строками (`rows`), `minRows`;
  - готовность (`readiness`, прогресс листа по ней);
  - `bind`/`entity` для шага 4;
  - `formerAnswers` («Прежние графы»);
  - `suggestWorkbookMapping`/`convertAnswer` (перенос по названиям, число → строка).
- Сервер:
  - вшитые курсы и их засев удалены (решение Q36);
  - `POST /workbooks/templates` принимает `{markdown}`;
  - без пометки ключ берётся от шаблона с тем же названием;
  - версия растёт сама, если текст изменился;
  - обновление версии переносит ответы (а не копирует), подписывает оставшиеся «прежние» и переводит лист у книг.
- Клиент:
  - графы новых типов, пустые строки и карточки из образца;
  - «Прежние графы» на листе;
  - загрузка `.md`;
  - сопоставление при обновлении подставляется само.
  - Пример `client/public/workbook-example.md` и инструкция автору переписаны под Markdown.
