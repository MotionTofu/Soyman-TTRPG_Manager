# Четыре концепта тетради

30 сентября 2026 года. Встроенная генерация imagegen. Это визуальные концепты; функции на изображениях пока не реализованы. Предыдущая реализация остановлена, рабочая база по Library v2 не мигрирована.

Требования — [brief.md](brief.md). Полные промпты — [prompts.md](prompts.md).

## 1. Тетрадь-разворот

Спокойный разворот: пояснение слева, ответы справа; главы на выступающих закладках, листы по верхнему краю.

![Тетрадь-разворот](E:/Claude/01_Blender/.scratch/workbook-redesign/concepts/01-quiet-spread.png)

## 2. Походный блокнот

Одна рабочая страница, компактные строки и отдельная сворачиваемая подсказка. Закладки сверху. Лучше подходит для небольшого окна.

![Походный блокнот](E:/Claude/01_Blender/.scratch/workbook-redesign/concepts/02-field-journal.png)

## 3. Комикс-разворот

Иллюстрированный пример слева, спокойная страница записи справа. Самый выраженный комиксный характер; для универсальных шаблонов иллюстрации должны оставаться необязательными.

![Комикс-разворот](E:/Claude/01_Blender/.scratch/workbook-redesign/concepts/03-comic-workbook.png)

## 4. Тетрадь рядом с книгой

Окно тетради поверх читалки, со сворачиванием в плашку. Демонстрирует одновременное чтение и письмо внутри приложения.

![Тетрадь рядом с книгой](E:/Claude/01_Blender/.scratch/workbook-redesign/concepts/04-overlay-notebook.png)

Актуальное направление после обсуждения: двухстраничная тетрадь и читалка из №4; обычные заметки и задания используют единую систему записей. Оформление Markdown общее для книг, без обязательного изменения файлов. Реализация приложения остаётся приостановленной до проверки макетов.
