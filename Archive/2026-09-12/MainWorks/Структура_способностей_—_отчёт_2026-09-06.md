# Структурность способностей — отчёт о работе (2026-09-06)

Задача: дать умениям собственные пулы uses с тратой, лентой, сбросом и
тофу-пипсами; разметить детерминированные способности; заложить ChoicePool.
Гриль: 2 раунда, все ответы «да». Рабочий план:
`MainWorks/Структура_способностей_ДнД_—_план_2026-09-06.md`.

## Модель (клиент, без новых таблиц)

- `DndCost` += `ownResource?`, `resourceLabel?`, `maxAbility?`,
  `restore? {pool, amount}`. Без флага `uses` — только текст цены.
- Пулы выводятся ключом `feature:{entryId}` в те же `resourceUsed` /
  `resourceBonus` (`featurePools()` в `dndResources.ts`, дедуп по ключу).
  Максимум: число, либо модификатор характеристики (мин 1).
- Трата из окна строки — по тому же ключу; `resourceLabel` — трата из
  пула по названию (ключи классовых пулов персонажеспецифичны).
- Сброс на отдыхе по `per` (`day` → долгий); короткий чинит короткое.
- Кнопка «Восстановить (N пул)» в строке пула — одним сохранением.
- Редактор: флаг + применения + восполнение + maxAbility + restore —
  в строке стоимости (`EffectList.tsx`).
- Без `entryId` (вписано руками) пула нет — цена текстом, как раньше.

## Тофу-пипсы

- `TofuPips.tsx`: слепок маскота под 18px (куб, контур, глаза). Целая —
  канон `#f5ead3`/`#241e18` (§12/§23, темонезависимо); съеденная — блеклый
  контур в цвете контекста. Отдельной головы в SVG не было — рисовали сами.
- Замена: лента «Действий» + строки «Ресурсов». Кости хитов, спасброски,
  ячейки — не тронуты.

## Грабли именно этой задачи

- `walkSpeed`/цены снаряжения в `data.cost` — строкой («750 зм»), это не
  `DndCost`: в аудите фильтровать по `kind`.
- `resource` без ключа = мёртвая кнопка траты (было 5 шт).
- `amount: null` + флаг = пул max 1 (дефолт); осознанный `ownResource: false`
  (бард) — уважать, не перетирать молча.

  цвета, не тема.
