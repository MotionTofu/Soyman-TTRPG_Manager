# Как сделать рабочую тетрадь для SoyMan

Тетрадь состоит из шаблона и заполненных экземпляров. Один шаблон подходит многим проектам; ответы каждого автора хранятся отдельно. Редактор не требует названия курса, количества уроков или особых тегов.

1. Скачайте `workbook-example.json` из «Тетради и шаблоны».
2. Замените название, инструкции и поля. Сохраните JSON в UTF-8.
3. Импортируйте файл в «Тетради и шаблоны». Создайте экземпляр, дайте ему название; при желании укажите кампанию, сеттинг или приключение.
4. В книге нажмите «Рабочая тетрадь», выберите шаблон, свой экземпляр и лист. Несколько книг могут открывать один экземпляр на разных листах.
5. Откройте тетрадь отдельно во время чтения. Её можно вручную разместить в подразделе/на полке; создание экземпляра само по себе не добавляет разделов библиотеки.

## Формат

Верхние поля: `format: "soyman-workbook"`, `schemaVersion: 1`, уникальный `key`, целочисленная `version` от 1, `title` и список `sheets`. Необязательные `description` и `source` описывают происхождение. В листе нужны `key`, `title`, `fields`; `instructions` — Markdown, обычные пояснения автора.

Поле содержит `key`, `label`, `type`; необязательный `hint` — короткая подсказка.

| Тип | Назначение | Дополнительные поля |
| --- | --- | --- |
| `text` | Многострочный ответ | — |
| `number` | Числовое значение | — |
| `choice` | Один вариант | `options`: список строк |
| `checklist` | Несколько отметок | `options`: список строк |
| `link` | Ссылка на материал | — |
| `table` | Строки, которые пользователь добавляет и переставляет | `columns`: простые поля |
| `group` | Повторяемые карточки со своими полями | `fields`: поля карточки |

Ключ начинается с латинской буквы и содержит до 80 латинских букв, цифр, дефисов или подчёркиваний. В пределах листа ключи полей уникальны; в таблице/карточке уникальны ключи дочерних полей. Ключи листов уникальны во всём шаблоне. Название можно менять без изменения ключа — так ответы остаются на своих местах.

Сначала сделайте один обычный лист и одну повторяемую карточку, импортируйте, заполните и проверьте экспорт. Затем добавляйте остальные листы. Пояснения сохраняйте в `instructions`, не превращайте их в обязательные ответы. Пустую форму из Markdown следует переработать в поля, а не вставлять как одно большое поле «Ответ».

## Версии и сохранность

Опубликованная версия неизменна. Для исправленного шаблона увеличьте `version`, сохраняя его `key`; импорт версии с другим содержимым под тем же номером отклоняется. Экземпляры продолжают использовать свою прежнюю версию до явного обновления через «Версии шаблона».

При переименовании ключа укажите сопоставление старого поля новому. Отсутствующие в новой версии ответы сохраняются и включаются в раздел Markdown-экспорта «Сохранённые ответы прежних полей». Изменение типа существующего заполненного поля может потребовать нового ключа: прежний ответ останется сохранённым.

Строки и карточки имеют постоянный `_id`, который редактор создаёт сам. При ручном импорте ответов идентификаторы строк должны быть уникальными; перестановка строк не меняет их идентификаторы.

Автосохранение проверяет номер ревизии. При правке двух окон ответы разных полей объединяются; для одного и того же поля, таблицы или группы выбирается целая версия ответа. До разрешения конфликта ввод остаётся в текущем окне и в локальном черновике.

## Экспорт, импорт и архив

«Экспорт .md» включает инструкции и заполненные ответы. «Экспорт с шаблоном» создаёт JSON с версией шаблона, ответами и ссылками на книги по постоянным ключам. При импорте связи восстанавливаются для книг, уже существующих в хранилище. Этот файл не переносит сами PDF, изображения и аудио — для них используйте полную резервную копию хранилища.

Импорт существующего экземпляра не перезаписывает его ответы. Новый независимый экземпляр того же шаблона создавайте кнопкой «Создать». Архив экземпляров и шаблонов доступен в «Тетради и шаблоны»; архив шаблона не удаляет заполненные экземпляры.

## Ограничения первой версии

До 200 листов, до 200 полей в блоке, до 4000 полей во всём шаблоне. До 500 строк/карточек в одном ответе. Шаблон и ответы — по 2 млн символов; файл импорта — до 4 МБ. В таблицах допустимы простые колонки. Поля не запускают код и не выполняют автоматические изменения сущностей кампании.
