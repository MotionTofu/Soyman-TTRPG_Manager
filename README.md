# SoyMan TTRPG Manager

Личный настольный менеджер ролевых кампаний — пока что для D&D 5.5, в последствии добавится Legend in the Mist и другие системы. Electron-приложение с собственным Express-сервером и SQLite-базой, полностью офлайн, с опциональной синхронизацией для игроков через тот же веб-клиент — он мобильно-адаптивен и переключает интерфейс по роли учётной записи (мастер/игрок).

## Возможности

- **Кампании и сессии** — календарь, финансы, подготовка к сессии, хроника, "Для игроков".
- **Сеттинги** — география (локации с картами), население (существа), общины, ресурсы, граф связей.
- **Компендиум систем** — классы, заклинания, предметы, бестиарий, справочник механик; отдельно для D&D 5.5 и Legend in the Mist.
- **Статблоки персонажей и существ** — полностью структурированные, с вычисляемыми полями (КЗ, бонусы, ячейки заклинаний), мастером создания и 14 визуальными темами.
- **Пульт сессии** — трекер инициативы, ход боя, панели для второго монитора, показ изображений игрокам.
- **Мобильно-адаптивный клиент** — тот же веб-клиент подстраивается под телефон, с realtime-синхронизацией через WebSocket для роли игрока.
- **Импорт** — Long Story Short (JSON) прямо в структурированный статблок персонажа.
- **Автообновление** — GitHub Releases + electron-updater, с подтверждением перед установкой.

## Структура репозитория

```
client/       — основной веб-клиент (React + TypeScript + Vite), мобильно-адаптивный
server/       — backend (Express + better-sqlite3)
electron/     — упаковка десктоп-приложения
scripts/      — вспомогательные скрипты сборки
```

## Разработка

```bash
npm run build:server   # собрать backend
npm run build:client   # собрать клиент
npm run electron       # запустить десктоп-версию локально
```

## Сборка релиза

```bash
npm run dist:empty   # portable + NSIS, без предзаполненных систем/сеттингов
npm run dist:full    # portable + NSIS, с сид-данными (seed-full/)
```

Автоматическая сборка и публикация релиза на GitHub происходит через GitHub Actions при пуше тега вида `v1.2.0` (см. `.github/workflows/release.yml`).
