Первая сессия
с нуля

Семь шагов — по порядку

Не пропускай первые три: сессия без кампании и состава — пустая дата, вести нечего.

01 / 07

Мир: система + сеттинг

⏱ 2 минуты · делается один раз

Главная → «Твоя первая легенда»
  1. На Главной открой герой Твоя первая легенда → шаг 1 Система. Выбери D&D 5.5 (SystemOnboardingModal).
  2. Шаг 2 Сеттинг → создай мир: например Вотердип (SettingOnboardingModal).
  3. Проверь: шаги 1–2 стали ✓, шаг 3 разблокировался.
Система = правилаСеттинг = мирБез них кампания пустая
Ловушка: кнопка «Новая кампания» без этого серая и пишет «Сначала заведи систему». Это не баг — так задумано.
02 / 07

Кампания: визард

⏱ 3 минуты · сердце всего

Кампании → Новая кампания
  1. Иди в Кампании → Новая кампания (CampaignWizard: Основы → Оплата → Система и сеттинг → Условия).
  2. Заполни Название ≤ 80 — например Драконий куш. Выбери Моя роль: Я Мастер, Тип: кампания / ваншот.
  3. Оплата: free / paid / conditional. Для платной — Тип ставки: с человека / со стола + Сумма + Валюта RUB. Привяжи систему и сеттинг из шага 01.
  4. Нажми Создать и перейти в кампанию.
namerole = gmtypepayment_typesession_ratesystem_id + setting_id
Живой пример из базы: Вотердип · Эстария · Фанделвер · «Однажды в Березе» (ваншот) — реальные кампании, не выдумка
03 / 07

Стол: игроки + персонажи

⏱ 3 минуты · кто сидит за столом

Кампания → вкладка Состав
  1. Внутри кампании открой Состав. Нажми добавить → выбери из списка (POST /campaigns/:id/roster/:playerId).
  2. Нового заведи в Игроки → + Новый игрок (PlayerCreationModal: name + notes).
  3. Персонажа привяжи в карточке игрока: campaign_id + player_id + character_name. Иначе в пульте будет пусто в блоке «Персонажи игроков».
Player: namerosterCharacter: character_name
Проверка: если во вкладке Резюме → Игроки видишь «В составе кампании нет игроков» — ростер не собран, сессию вести некому.
Пример стола: Брон · Джарольд · Зарр игроки: Саня, Лиза, Колян
04 / 07

Дата: создать сессию

⏱ 1 минута · три входа, форма одна

Герой · Календарь · Кампания
  1. Выбери удобный вход — форма Новая сессия везде одна: Кампания (select) + Дата (date) + Время начала (time).
  2. Вариант А — герой шаг 5 Сессия: кампания подставится сама. Вариант Б — Главная → Календарь → клик по дню → + Добавить сессию. Вариант В — Кампания → календарь → ПКМ → Создать сессию (тут же Статус, Оплата, Ставка, повтор).
  3. Нажми Создать. Серверу нужны только campaign_id + date — остальное допишешь в карточке. Статус по умолчанию planned.
campaign_id*date*start_timestatus = plannedpayment_overridestake_override
Для ваншота: в форме есть Скопировать подготовку из прогона — подтянет сцены с прошлого прогона, не пиши заново.
05 / 07

Мясо: обзор + подготовка

⏱ 4 минуты · что будет за столом

Карточка /sessions/:id
  1. Открой карточку сессии. Шапка: Кампания — Сессия №N, карандаш Переименовать сессию, полоса Когда / В мире / Номер.
  2. Вкладка Обзор — факты: Статус, Оплата (Как в кампании…), Ставка, За столом: Дата/Начало, В мире: Год/Месяц/День + дата окончания, Нераскрытые тайны.
  3. Вкладка Подготовка — мясо: Задумка на сессию + Боевая тема, дерево приключение → глава → сцена (SessionSceneTree), Сюжетные персонажи, Локации, Препятствия, Потенциальный лут, Шпаргалки. Файлы — во вкладке Ресурсы.
Задумкаstory-treeplanned scenesлутшпаргалкиресурсы
06 / 07

Игра: пульт стола

⏱ вечер · смотри в игроков, не в ноут

Кнопка «Пульт сессии» → /live
  1. В карточке нажми Пульт сессии (/sessions/:id/live). Это второй монитор: Задумка / Основные события (Видно игрокам), SceneSwitcher (Сейчас/Дальше).
  2. Инициатива — блок Трекер инициативы: кнопка В инициативу из карточки существа, поля initiative, HP, conditions, сортировка сама. Подсветка — combat_active. Спец-строки: Действие логова (20).
  3. Показ игрокам — PresentationPanel (/live/show: black | scene | cover) + Боевая тема (4 канала: Background / Ambient / Weather / Stingers, кроссфейд). Панели: персонажи, локации, лут, тайны, напоминания.
initiative-trackerscene-switchershow image4ch audiosecond monitor
Полотно ≠ сессия: Полотно (/canvas) — узловой редактор мира без даты. Сессия тянет из него сцены через scene-search и запускает в пульте. Не готовь в пульте — готовь в полотне.
07 / 07

Финал: состоялась + разбор

⏱ 2 минуты · деньги и память

Резюме → Отметить проведённой
  1. После игры: Резюме → Отметить сессию проведённой (SessionOutcomeModal) или Главная → «Игры прошли, но не отмечены» → Разобрать, или прямо в пульте Сохранить и завершить сессию.
  2. Заполни таблицу: Пришёл ✓, Оплачено, Ставка, Прощено → earned. Напиши Основные события — это увидят игроки.
  3. Статус станет held. В резюме появятся Прошло в мире N дней · Сыграно сцен · Раскрыто тайн. Незаигранные сцены сервер сам перенесёт на следующую дату.
status = heldпришёл / оплаченоearnedсобытия игрокам
Готово: Сессия №1 «Драконий куш» — Состоялась · 3 пришли · 2 оплатили следующая дата уже ждёт сцены

Не путай три сущности

Новички готовят не там. Запомни схему один раз.

Полотно/canvas

Мир без даты: приключения, сцены, свободные доски, пины на карте. Готовь здесь. 66 досок — не список глав, а схема с переходами и проверками.

Сессия/sessions/:id

Дата + план на вечер: дерево сцен, лут, шпаргалки, тайны. Тянет сцены из полотна через scene-search. Собирай здесь.

Пульт/live

Живой стол: инициатива, второй монитор, «показать картинку», звук 4 канала. Веди здесь. Смотри в игроков, не в ноут.

Чек-лист «готов к столу»

Распечатай в голове. Кликай — галочки живут в браузере.

FAQ — где все спотыкаются

Четыре грабли первой сессии.

Кнопка «Новая кампания» серая. Что делать?
Заведи систему и сеттинг через герой «Твоя первая легенда» (шаги 1–2). Без них кампания заблокирована — так задумано, а не баг.
Создал сессию, а вести нечего — пусто. Почему?
Ты пропустил шаг 03 (Состав) и 05 (Подготовка). Сессия — только дата. Наполни: ростер игроков + дерево сцен во вкладке «Подготовка».
Где готовить приключение — в сессии или в полотне?
Готовь в Полотне (/canvas) — это мир без даты. В сессию подтягивай нужные сцены через scene-search. Пульт — только для ведения, не для подготовки.
Как отметить, кто пришёл и кто заплатил?
Резюме → «Отметить сессию проведённой». Там таблица: Пришёл / Оплачено / Ставка / Прощено. После этого статус станет «Состоялась», а деньги посчитаются в earned.
