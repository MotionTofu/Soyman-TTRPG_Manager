# OneShot — ревизия

## Находки

Найдено попутно при подготовке к первой игре (2026-09-23) и не исправлено.

- **Нет «Благословенного воина»** среди боевых стилей справочника, а
  «Воин-друид» (стиль Следопыта) предлагается Воину.
- **Заклинательная характеристика одна на лист.** «Мистический воин» и
  «Посвящённый в магию» дают заклинания со своей характеристикой — лист
  считает их по классовой. Стиль «Мистический воин» размечен без неё.
- **Доспехи с выбором основы:** «Эльфийская кольчуга», «Кольчуга ифритов»,
  «Доспех трамонтаны» — КЗ не размечен, миграция их перечисляет, а не угадывает.
- **Предметы с условием:** «Ловящий стрелы щит», «Защитник», «Меч Каса»,
  «Посох акробата», «Жезл бдительности» — прибавки зависят от выбора или
  ситуации, не размечены.
- **КЗ не смоделирован:** «Дубовая кожа» (минимум 17), «Мастер средних
  доспехов» (Лов до +3), «Оборонительный дуэлянт», «Славная защита»,
  «Песнь клинка» — ручная прибавка на листе.
- **«Щит веры» на союзника** показывается у заклинателя: концентрация
  считается эффектом на себя.
- **Старые листы:** у черты происхождения нет `entryId` — её эффекты не
  работают, пока черту не выбрать заново.
- **Визард не надевает оружие** из набора — у нового персонажа пустые «Действия».
- **У питомца из бестиария нет счётчика хитов.** Только жетон с карточкой;
  счётчик есть лишь у спутников по чертежу. Решено отложить до после игры
  (гриллинг 2026-09-23, Q3).
- **Справочник закреплён за персонажем.** Новая версия справочника (например,
  с карточками существ) достаётся только новым персонажам. Для первой игры
  не важно — игроков ещё нет; после выкладки менять справочник нужно с
  новой `--catalog-version` и с пониманием, что старые листы её не увидят.
  Статус: так задумано, записано для памяти.

## Исправлено 2026-09-23

- Боевой стиль в визарде не сохранялся (`prev.map` по пустому массиву) —
  Воин, Паладин и Следопыт не создавались. `DndCharacterWizard.tsx`.
- Экспорт отвергал «Первобытного зверя»: хиты у него внутри вариантов.
- Питомцы из бестиария: поиск, карточка существа и экспорт — справочник
  несёт игроцкую карточку (статблок, роли, тактика; без секрета).
- Визард надевает доспех и щит из набора, если персонаж ими владеет.
- Кнопка «В профиль» в карточке существа скрыта без пользователя (OneShot).
- Класс не давал владение доспехами на листе: визард и смена первого класса
  на листе кладут `armor_profs` класса в «Владения» строками, как инструменты.
  Паладин из визарда: кольчуга и щит надеты, КЗ 18, пометок «без владения»
  нет. Листы, созданные раньше, не пересчитываются.
- «Флажки оружейных приёмов без подписей» — ложная находка: все флажки внутри
  `<label>`. Настоящее: имя сливалось с уроном («Дубинка1к4») — добавлен пробел.
- **КЗ и боевые стили считаются из эффектов** (гриллинг 2026-09-23, 23 вопроса).
  Числовой `defense` (прибавка, формула базы, условие по доспеху), фильтр
  оружия у прибавок к атаке и урону, активные заклинания (плашка под КЗ,
  ✕ и долгий отдых снимают), настройка предмета, чувства от черт, разбивка
  КЗ по нажатию с «не учтено: причина». Счёт по имени умения удалён.
  Проверено в браузере: Оборона, Доспехи мага + Щит (13→16→21), Защита без
  доспехов, Стрельба из лука, Дуэлянт со щитом, два оружия, ненастроенное
  Кольцо защиты, реакции Защита/Перехват, Сражение голыми руками и вслепую,
  «Доспех +1» → Кольчуга +1. Разметка справочника — миграция
  `dnd_combat_effects_seeded`.
- Бонусы черт не считались вовсе: лист брал числа из неразвёрнутых умений
  (у «Бдительного» инициатива не прибавлялась); у черты происхождения из
  визарда не было `entryId`.
- Два одинаковых оружия давали две одинаковые строки атаки.
- В выборе основы для «Доспеха +N» были магические доспехи.
- «КД» → «КЗ» в визарде и на постере персонажа.
