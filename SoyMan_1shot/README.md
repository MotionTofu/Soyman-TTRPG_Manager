# OneShot SoyMan

Отдельная поставка с настоящими компонентами визарда, повышения уровня и листа D&D 5.5 из SoyMan, общими расчётами и стилями. Цифровые броски отключены.

## Запуск

Нужны установленные зависимости соседнего client. Из этой папки:

- npm start — текущий сайт http://localhost:4318/.
- npm run build — сборка в app-dist.
- npm test — проверки справочника и лабораторного экспорта.
- node ../client/node_modules/typescript/bin/tsc -p tsconfig.json — проверка типов.

Для локальной разработки node prepare-catalog.mjs читает активную базу SoyMan в режиме read-only и создаёт private/catalog.json. Затем нажать «Подключить справочник этого SoyMan». Персонажи и кампании не копируются. Private исключена из Git и публичной сборки. Статической сборке нужен импорт JSON системы через интерфейс.

## Текущий этап

Общий визард и лист, игровые изменения с сохранением в IndexedDB, независимые персонажи и закреплённая версия справочника. Проверка ревизии предотвращает молчаливое затирание правок другого окна. После ошибки запись останавливается; видимый лист можно скачать.

Резервная копия JSON содержит персонажа и весь подключённый справочник. Восстановление создаёт нового персонажа. Это промежуточное восстановление, а не финальный экспорт со срезом используемых записей.

Кнопка «Скачать автономный HTML» собирает настоящий React-лист, шрифты, портрет и выбранные записи справочника с общими игровыми правилами в один файл. Сеть запрещена политикой CSP. В автономном листе изменения сохраняются кнопкой «Скачать обновлённую копию»; исходный файл автоматически не перезаписывается. Новые предметы и заклинания вводятся вручную, повышение уровня отключено. Поддержаны спутники по чертежам умений и заклинаний: хиты, КЗ, действия, варианты и состояние используют общие компоненты SoyMan. Экспорт спутников из бестиария, отдельных статблоков и внешних изображений пока блокируется с объяснением.

Пока нет аккаунтов, облачной синхронизации и установки полноценного листа как PWA. Не завершена проверка полноты косвенных зависимостей и классовых исключений. Открытие локального HTML на iOS/Android требует отдельного испытания; наличие HTML не означает установку на главный экран.

## Лабораторный прототип

npm run start:lab открывает предыдущую проверку носителя на http://localhost:4317/. npm run build:lab собирает её в dist. Только лабораторная версия сейчас содержит service worker и индивидуальные manifest. Её проверки установки не подтверждают готовность установки полноценного React-листа.
