### С2 — Расширение загруженного файла берётся из его имени
**Вид:** дефект · **П1**

**Где.** `routes/players.ts:211`, `characters.ts:291,402,424`, `artifacts.ts:323`, `appSettings.ts:58`, `canvas.ts:2768`, `campaigns.ts:38,207,230`, `gallery.ts:24,116`; раздача — `index.ts` (`express.static(VAULT_ROOT)`).

**Откуда.** `ToDo/06` П0.3 (аватар), П0.5 (mimetype).
**Готово, когда.** Расширение выводится из проверенного MIME (или из сигнатуры файла), а `/files` не отдаёт `text/html`/`javascript`.

### С35 — Пересборки таблиц в миграциях без транзакции
**Вид:** дефект · **П2**
Персонажи пересобираются безопасно (снимок, транзакция, `finally`), а шесть
соседних пересборок — нет: CREATE/COPY/DROP/RENAME идут отдельными
автокоммитами. Обрыв после CREATE оставляет `*_new`, и следующий запуск
падает на «table … already exists» — сервер не стартует. Обрыв между DROP и
RENAME оставляет данные в `*_new`, а схема заводит пустую таблицу рядом.
Касается только старых баз (у друга своя).
**Где.** `server/src/db/db.ts`: `generic_links` :787–803, `resources` :888–915, `story_scene_rewards` :4958–4976, `story_scenes` :5221–5251, `story_milestones`/`story_secrets` :5298–5306, `story_arc_transitions` :5880–5893. В транзакции только `characters` :584–629 и `map_bindings` :6305.
**Проверено 2026-10-21.** SQL блока `generic_links` взят из `db.ts` и прогнан на `:memory:`: при оставшемся `generic_links_new` — «table generic_links_new already exists», `foreign_keys` остаётся 0; обрыв перед RENAME — в базе только `generic_links_new`.
**Откуда.** `A/.scratch/audit-260914/issues/01` (H-21, R-7) — сам тикет про `characters` закрыт `013b3455`.
**Готово, когда.** Каждая пересборка — в транзакции с `DROP TABLE IF EXISTS *_new` в начале и `foreign_keys` в `finally`; тест отказа между шагами на временной базе.

### С36 — Импорт: ошибка сверки выдаётся за «Это не JSON»
**Вид:** дефект · **П1**

таймаута применения сообщение предлагает «попробуйте ещё раз», хотя импорт

**Проверено 2026-10-21.** Чтением: `requestPlan` — `try/finally` без `catch`, вызывается внутри `try { JSON.parse … }`.
**Откуда.** `audit-260914` 05; `errs.md` H-3, H-4, M-1…M-3.
**Готово, когда.** Ошибка файла, плана и применения различаются в тексте; отказ сервера не сбрасывает файл и выбор сопоставлений; после таймаута применения — «результат неизвестен, сверьте историю пачек».

### С37 — Редактор темы: «Отмена» оставляет на экране чужую тему
**Вид:** дефект · **П2**

**Откуда.** `audit-260914` 11; `errs.md` C-2, C-3.
**Готово, когда.** «Отмена» возвращает тему из `prefs.themeId`; тест на правку неактивной темы.
