# Дизайн-система «PUNK ZINE» — RPG Manager

Собрана из четырёх пар референсов (desktop + mobile): Apocalypse/RPG Manager (неон),
Punk Master / GAME ON (жёлто-розовый коллаж), SOLARPUNK (газетный зин), Punk Your A$$
(рваная газета). Документ описывает общий язык, а не четыре разных темы: одна система,
три палитровых режима.

---

## 1. Что общего у всех четырёх референсов

Прежде чем токены — наблюдения, из которых они выведены.

**Панк-DIY как базовая метафора.** Ни один референс не выглядит как «приложение».
Все выглядят как артефакт: постер, обложка альбома, самиздатовский журнал, стена с
наклейками. Интерфейс притворяется физическим объектом — бумагой, краской, ксероксом,
неоновой вывеской. Это главное, что отличает их от дженерик-дашборда.

**Ровно три цвета.** Везде: тёмная (или бумажная) база + один кричащий акцент +
один вторичный. Четвёртого цвета нет нигде. Неон: чёрный + кислотно-зелёный + маджента.
Punk Master: чёрный + жёлтый + маджента. Solarpunk: кремовый + чёрный + красный.
Punk Your A$$: чёрный + кремовый + красный. Полутонов почти нет — цвет идёт плашками
на 100 % насыщенности, а градации делаются прозрачностью, а не новыми оттенками.

**Типографика — двухголосая, с огромным контрастом.** Заголовки: тяжёлый
сжатый гротеск или рукописный/трафаретный шрифт, ВСЕГДА КАПС, часто с наклоном,
обводкой, «вырезан из бумаги». Тело и метаданные: маленький, спокойный, часто
моноширинный или узкий гротеск, тоже капсом, с большим трекингом (0.08–0.15em).
Между h1 и body — разрыв в 4–6 раз по кеглю. Промежуточных размеров мало: система
скачет, а не плавно нарастает.

**Сетка жёсткая, содержимое — нет.** Под всем лежит обычная колоночная сетка
(сайдбар 240–280 / основное поле / правый рельс 300–340 на десктопе). Ощущение хаоса
создаётся не сломом сетки, а тем, что *внутри* ячеек лежат наклонённые, оборванные,
перекрывающиеся элементы. Это ключевой приём: порядок в раскладке, беспорядок в отделке.
Соответственно, «разнузданность» добавляется на уровне карточки, а не на уровне лейаута.

**Ритм блоков — «герой + плитки + список».** Каждый десктопный дашборд построен
одинаково: один большой héro-блок с иллюстрацией (текущая кампания), под ним ряд
одинаковых плиток-карточек 3–4 в ряд, ниже — плотный список строк. Правый рельс —
стопка узких виджетов (ближайшая сессия, быстрые действия, заметки, персонажи).
Взгляд идёт: крупное → среднее → мелкое, сверху вниз, без возврата.

**Пространство — плотное, но не тесное.** Внешние поля щедрые (32–48 px), внутренние
компактные (12–16 px). Между секциями — крупный вертикальный интервал (32–40 px),
внутри секции строки идут через 8–12 px. Пустота работает как рама, а не как воздух
между элементами: карточки прижаты друг к другу, а вокруг всего блока — тишина.

**Обязательный «шум».** В каждом референсе есть слой, который не несёт информации:
халфтон-точки, зерно бумаги, брызги краски, рваный край, штрих-подчёркивание маркером,
скотч, штрихкод, номер выпуска. Это 5–10 % площади экрана. Без него система
разваливается в обычный тёмный UI.

**Один крупный маскот/иллюстрация на экран.** Череп, панк с гитарой, гриб взрыва.
Он живёт в правом нижнем углу или в héro-блоке, частично выходит за границы контейнера
и никогда не дублируется. Это якорь настроения.

**Настроение.** Дерзко, громко, с юмором, чуть агрессивно — но не мрачно. Это не хоррор
и не киберпанк-нуар: везде есть шутка (слоганы «ХАОС — НАШ ДМ», «PUNK UP YOUR RPG»,
«РОК НИКОГДА НЕ ЗАКАНЧИВАЕТСЯ»). Интерфейс подмигивает пользователю.

**Мобильные версии не упрощают, а сжимают.** Тот же цвет, та же типографика, тот же
шум. Меняется только раскладка: одна колонка, липкий нижний таб-бар, карточки во всю
ширину, статы в ряд по 3–4.

## 3. Цвет

### 3.1 Три режима

Один набор семантических токенов, три подстановки. Переключение — атрибут
`data-skin` на `<html>`.

```css
/* Базовый: ZINE (Solarpunk) — бумага, чёрный, красный */
:root, [data-skin="zine"] {
  --paper:        #EDE7D9;  /* фон-бумага */
  --paper-2:      #E2DAC8;  /* вложенные поверхности */
  --ink:          #12100E;  /* основной текст и плашки */
  --ink-2:        #3A352E;
  --muted:        #6E675C;
  --accent:       #D6321E;  /* красный: акцент, статусы, ссылки */
  --accent-2:     #12100E;  /* вторичный = чернила */
  --surface:      #12100E;  /* тёмная карточка на светлом фоне */
  --on-surface:   #EDE7D9;
  --line:         rgba(18,16,14,.28);
  --glow:         none;
}

/* RIOT (Punk Your A$$ / пара 4) — инверсия: чёрный лист, бумажные обрывки */
[data-skin="riot"] {
  --paper:        #0B0B0B;
  --paper-2:      #141414;
  --ink:          #F2EDE1;
  --ink-2:        #C9C2B4;
  --muted:        #8A8378;
  --accent:       #C7261B;
  --accent-2:     #F2EDE1;
  --surface:      #F2EDE1;   /* светлый обрывок на чёрном */
  --on-surface:   #0B0B0B;
  --line:         rgba(242,237,225,.22);
  --glow:         none;
}

/* NEON (пара 1 / пара 2) — кислота */
[data-skin="neon"] {
  --paper:        #07070A;
  --paper-2:      #0F0F14;
  --ink:          #F0FFE8;
  --ink-2:        #B9D6AC;
  --muted:        #6F7A6A;
  --accent:       #FF2E88;   /* маджента */
  --accent-2:     #B6FF2E;   /* кислотный лайм */
  --surface:      #0F0F14;
  --on-surface:   #F0FFE8;
  --line:         rgba(182,255,46,.35);
  --glow:         0 0 12px rgba(182,255,46,.45);
}
```

Жёлтый вариант пары 2 — это `neon` с `--accent-2: #FFE500`; отдельным режимом не делаем.

### 3.2 Правила использования

- Акцент занимает **не больше 15 % площади** экрана. Он для: активного пункта меню,
  первичной кнопки, статуса «в процессе», числа-героя, одного слогана.
- Никаких градиентов кроме «краска на бумаге» (см. §5). Заливка — плоская.
- Оттенки строятся только через прозрачность базового токена (`/.08`, `/.16`, `/.28`),
  новые hex не заводим.
- Тёмная карточка на светлом фоне (и наоборот) — главный приём иерархии, а не тень.
  Тени в системе нет вообще; глубину даёт инверсия и рваный край.

## 4. Типографика

### 4.1 Три голоса

| Роль | Гарнитура | Применение |
|---|---|---|
| **Display** | Сжатый тяжёлый гротеск (`Anton`, `Oswald 700`, `Archivo Black`) | h1–h2, названия кампаний, слоганы. Всегда КАПС, `letter-spacing: -.01em`, `line-height: .92` |
| **UI** | Узкий гротеск (`Inter Tight`, `IBM Plex Sans Condensed`) | h3–h4, кнопки, лейблы, навигация. КАПС для лейблов, `letter-spacing: .10em` |
| **Body / Mono** | Моноширинный (`JetBrains Mono`, `IBM Plex Mono`) | тело, метаданные, числа, даты, статы. Строчные для абзацев |
| **Hand** (опц.) | Рукописный маркер (`Permanent Marker`, `Caveat 700`) | пометки, «мастер писал от руки», подчёркивания. Не больше 1–2 на экран |

### 4.2 Шкала (скачками, не плавно)

```css
--fs-hero:  clamp(40px, 6vw, 76px);  /* название кампании в héro */
--fs-h1:    clamp(28px, 3.4vw, 40px);
--fs-h2:    22px;
--fs-h3:    16px;
--fs-body:  14px;
--fs-meta:  12px;   /* капс + трекинг .10em */
--fs-micro: 10px;   /* капс + трекинг .14em — бейджи, штрихкод-подписи */
--fs-stat:  clamp(24px, 3vw, 34px);  /* число на кости/в плитке */
```

Правило: между соседними по иерархии элементами в блоке разница минимум **×1.6**.
Если два текста рядом близки по кеглю — один из них должен уйти в другую гарнитуру
или в капс с трекингом.

### 4.3 Заголовки секций

Единый паттерн на всех референсах: `▸ ИКОНКА + КАПС-ЗАГОЛОВОК` слева, ссылка
`ВСЕ … →` справа, между ними — тонкая линия или ничего. Заголовок допускает
«маркерное» подчёркивание (§5.3) или плашку-выделение.

## 5. Текстуры и «шум»

Слой, без которого система не работает. Реализуется CSS-ом, без картинок, где можно.

### 5.1 Зерно бумаги / плёнки

```css
.tex-grain::after {
  content: ""; position: absolute; inset: 0; pointer-events: none;
  opacity: .18; mix-blend-mode: multiply;   /* в тёмных режимах — screen, opacity .08 */
  background-image: url("data:image/svg+xml,…feTurbulence…");
}
```

### 5.2 Халфтон (пара 2)

```css
.tex-halftone {
  background-image: radial-gradient(currentColor 1.2px, transparent 1.3px);
  background-size: 6px 6px;
  opacity: .22;
}
```
Только как фон угла/полосы, никогда — под текстом.

### 5.3 Маркерное подчёркивание и плашка-выделение

```css
.mark-hi { background: var(--accent); color: var(--paper);
           padding: 0 .35em; transform: rotate(-1.2deg); display: inline-block; }
.mark-underline { background: linear-gradient(var(--accent), var(--accent))
                  0 88% / 100% .28em no-repeat; }
```

### 5.4 Рваный край

`clip-path` с 12–20 нерегулярными точками по кромке; для карточек — только верх и низ,
боковые кромки прямые (иначе ломается сетка). Два-три готовых `--tear-a/b/c`, чередуем,
чтобы соседние карточки не были одинаковыми.

### 5.5 Наклон

Разрешён `rotate(-2deg … 2deg)` для: бейджей, наклеек, слоганов, одной карточки в ряду.
Никогда — для текстовых блоков длиннее строки и для интерактивных списков.

### 5.6 Зинные маркеры

Штрихкод, «ISSUE 888», номер выпуска, крестики-звёздочки-анархия, скотч.
Норма: **2–3 таких элемента на экран**, всегда в `--muted` или `--ink` на 40 %.

## 6. Сетка, лейаут, ритм

### 6.1 Десктоп

```
┌──────────┬─────────────────────────────────┬───────────────┐
│ SIDEBAR  │ HERO (кампания, 16:6, картинка) │ RAIL          │
│ 256      │                                 │ 320           │
│          │ SECTION: плитки 3–4 в ряд       │ виджет        │
│          │ SECTION: список строк           │ виджет        │
│  ▸ лого  │                                 │ виджет        │
│  ▸ меню  │                                 │ маскот        │
│  ▸ юзер  │                                 │               │
└──────────┴─────────────────────────────────┴───────────────┘
gap 24 ·外部 padding 32–40 · max-width контента 1440
```

- Сайдбар: лого-«наклейка» сверху, пункты меню с иконкой 20 px, активный —
  плашка/мазок акцентом. Снизу — карточка пользователя.
- Правый рельс: 3–4 виджета высотой 140–260, каждый — самостоятельная карточка
  с капс-заголовком.
- Ниже 1280 рельс уезжает под основное поле в 2 колонки; ниже 1024 — одна колонка.

### 6.2 Шаг

```css
--sp-1: 4px; --sp-2: 8px; --sp-3: 12px; --sp-4: 16px;
--sp-5: 24px; --sp-6: 32px; --sp-7: 48px; --sp-8: 64px;
```
Внутри карточки — 12/16. Между карточками — 16/24. Между секциями — 32/40.
Радиусы: **0 или 2 px**. Скруглений в системе нет (круглые — только аватары и
центральная кнопка таб-бара).

### 6.3 Карточка

Три вида, различаются ролью, не декором:
1. **Плитка-обложка** (кампания, мир) — картинка 3:4 или 16:10, поверх снизу
   градиент-в-`--paper` и капс-название, под ней 1–2 строки меты + прогресс-бар.
2. **Строка-список** (сессия, заметка) — 56–72 px высотой: дата-блок слева,
   заголовок + подзаголовок, справа мета и кнопка. Разделитель — 1 px `--line`.
3. **Виджет** — капс-заголовок, тело, одна ссылка/кнопка снизу.

Обводка карточки: 1–2 px `--ink`/`--line`. В `neon` — плюс `--glow`.

### 6.4 Прогресс-бар

Высота 6 px, фон `--line`, заливка `--accent`, справа — процент моношрифтом.
Без скруглений, без анимации-блеска.

### 6.5 Кости как подложка под числа (из пары 2)

Ключевой компонент. Число характеристики лежит **внутри силуэта кости**, а не в
квадратной плитке.

```
d20 (шестиугольник + внутренние рёбра) → основные характеристики, броски
d8  (ромб)                             → вторичные статы
d6  (квадрат с точками по углам)       → счётчики, ресурсы
```

- Силуэт — инлайн-SVG `<path>` с `fill: var(--accent)` или `fill: none;
  stroke: currentColor; stroke-width: 2`.
- Число — `--fs-stat`, Display-гарнитура, по центру, цвет контрастный к заливке.
- Подпись характеристики — `--fs-micro`, капс, **под** костью, не внутри.
- Ряд из 4–6 костей: `display: grid; grid-auto-flow: column; gap: var(--sp-3)`.
- Цвет кости кодирует смысл, а не украшает: акцент = активная/использованная,
  контур = обычная, `--muted` = недоступная.
- Заполненные (`fill`) и контурные кости в одном ряду не смешиваем.

## 7. Мобильная версия

Одна колонка, `padding: 16px`, карточки во всю ширину, héro 16:10.
Заголовки экранов — по центру, капс, между кнопкой «назад» и действием.

### 7.1 Нижний таб-бар (из пары 1)

```
┌─────────────────────────────────────────┐
│  ⌂        ⚔        ╔═══╗       🛠     ☰ │
│ ГЛАВНАЯ КАМПАНИИ  ║ ☠ ║  ИНСТРУМ.  ЕЩЁ │
│                   ╚═══╝                 │
└─────────────────────────────────────────┘
```

- 5 слотов, равной ширины; центральный — **приподнятая круглая кнопка** ø 56–60,
  вылезающая над баром на 18–22 px, залитая `--accent`, с иконкой-черепом.
  Вокруг — «лучевой» ореол (SVG-звезда/брызги) и в режиме `neon` — свечение.
- Высота бара 64 + `env(safe-area-inset-bottom)`. Фон `--paper-2`,
  верхняя граница 1 px `--line` (в `zine` — рваный край сверху).
- Иконка 24 px, подпись `--fs-micro` капс. Неактивные — `--muted`,
  активная — `--accent-2` (в `zine` — `--accent`), плюс микро-подчёркивание 2 px.
- Центральная кнопка — контекстное действие текущего экрана (бросок кости на главной,
  создание на списках), а не шестой раздел навигации.
- Тап: `scale(.94)` 90 мс. Никаких «прыгающих» иконок.

### 7.2 Мобильные статы

Ряд из 3 костей во всю ширину (`♥ HP · 🛡 AC · ✦ …`) под именем персонажа —
ровно как в паре 1, но силуэтами костей из §6.5.

## 8. Компоненты: краткий свод

| Компонент | Норма |
|---|---|
| Кнопка primary | Плашка `--accent`, текст `--paper` капс `--fs-meta`, `padding: 12px 20px`, радиус 0, без тени. Hover: `translate(-1px,-1px)` + жёсткая «тень-смещение» 3 px `--ink` |
| Кнопка secondary | Прозрачная, обводка 2 px `--ink`, текст `--ink` |
| Бейдж статуса | `--fs-micro`, капс, плашка акцентом или обводка, `rotate(-1.5deg)` допускается |
| Инпут | Прозрачный фон, нижняя линия 2 px `--ink`, фокус — линия `--accent`. Без рамок-коробок |
| Аватар | Круг, обводка 2 px, в списке персонажей — перекрытие −8 px |
| Модалка | Полноэкранная затемнённая подложка, окно с рваным краем сверху/снизу |
| Пустое состояние | Маскот + слоган Display-шрифтом + одна кнопка. Не «нет данных» |
| Тултип/тост | Чёрная плашка, капс, наклон −1° |

**Иконки.** Штриховые, 1.75–2 px, слегка неровные (hand-drawn), 20/24 px.
Библиотечные (Lucide) допустимы, но ключевые разделы получают рисованные.

## 9. Движение

Минимум, всё резкое: `--ease: cubic-bezier(.2,.8,.2,1)`, длительности 90/140/200 мс.
Разрешено: сдвиг-и-жёсткая-тень на hover, `scale(.94)` на тап, появление карточек
`translateY(6px) + opacity` со стаггером 40 мс. Запрещено: плавные пульсации, параллакс,
длинные fade, «дышащие» свечения (кроме одного элемента в `neon`).
`prefers-reduced-motion` отключает всё кроме смены цвета.

## 10. Правила, которые держат систему

1. Три цвета. Четвёртый — ошибка.
2. Сетка ровная, отделка кривая. Наклоны и рванина живут внутри ячейки.
3. Один маскот, 2–3 зинных маркера, один слоган на экран.
4. Радиусов нет. Мягких теней нет. Глубина — через инверсию и обводку.
5. Каждый экран: одно крупное, ряд среднего, плотный список мелкого.
6. Числа — моношрифтом и на костях, а не в круглых чипах.
7. Тексты интерфейса — с характером («Что планируем разрушить на этой неделе?»),
   но короткие. Шутка в подзаголовке, не в кнопке.
8. Если экран стал похож на обычный дашборд — не хватает §5.

## 11. Порядок внедрения в клиент

1. Токены (§3, §4.2, §6.2) — в `client/src/index.css` рядом с существующими темами;
   режимы через `data-skin`, как уже сделано для тем в `client/src/themes.ts`.
2. Шрифты — в `client/src/fonts.ts` (Display + Mono обязательны, Hand — по желанию).
3. Утилиты текстур (§5) — отдельный `client/src/zine.css`.
4. Компонент `<Die value label kind="d20|d8|d6" state />` (§6.5).
5. Мобильный таб-бар (§7.1) — в `client/src/layout/AppShell.tsx`.
6. Переверстать по порядку: главная → список кампаний → карточка персонажа → сессия.
