## Чего в облаке нет и чем это заменить

| Локально | В облаке | Что делать |
|---|---|---|
| Живая база `server/data/app.db` | нет (`*.db` в `.gitignore`) | Сервер на старте сам создаёт пустую базу и прогоняет миграции. Проверяй на ней, заводя свои тестовые записи. |
| Хранилище `E:\RPG-Vault` | нет | Картинки для проверки (карта места и т. п.) — любые свои тестовые файлы. |
| `.claude/launch.json` (`api` 3001, `client` 5173) | нет (`.claude/` в `.gitignore`) | `npm run dev --prefix server` и `npm run dev --prefix client`; клиент проксирует API на 3001. |
| Память Клода (`~/.claude/projects/.../memory`) | нет | Ключевые решения переписаны ниже. |
| `graphify-out/` | нет (в `.gitignore`) | Ориентируйся по коду и `docs/`. |
| Codex CLI для ассетов | нет | Ассеты не генерировать. Нужен ассет — записать предложение (что, где, размер) и оставить владельцу. |
| `node_modules`, сборка `shared` | нет | `npm ci` в `client/`, `server/` и `shared/`, затем `npm run build --prefix shared` — без него сервер не видит `@soyman/shared`. |
| Запуск сервера | падает на `E:\RPG-Vault` | `VAULT_ROOT=<папка> CONFIG_DIR=<папка> npm run dev --prefix server` — обе переменные вместе, папки в scratchpad. |

Пароли: только тестовые. Если пустая база просит завести пользователя — заведи
тестового Мастера с тестовым паролем, реальных данных владельца не вводить.

## Обязательные проверки (без пайпа: код возврата должен быть компилятора)

```bash
cd client && npx tsc -p tsconfig.app.json --noEmit
```
```bash
cd client && npx oxlint src
```
```bash
cd server && npx tsc --noEmit
```

`npx tsc --noEmit` в `client` не проверяет ничего — только `-p tsconfig.app.json`.
Ошибок oxlint быть не должно; предупреждений на 2026-10-02 — **222**, больше не
становится. Барьеры оформления: `node client/scripts/check-*.mjs` (spacing,
type-scale, inline-styles, page-frame, entity-page, list, raster-assets) —
новых записей в своих файлах не добавлять; отступление пишется комментарием
«инлайн-стиль намеренно — …» / «шаг мимо шкалы намеренно — …».

Остальное из `CLAUDE.md`, коротко: проектирование нового (модель данных,
экран, поведение) — только после `grilling` с владельцем; миграции только в
конец `migrateDatabase` в `server/src/db/db.ts`, по `ALTER` на колонку;
URL `/ui/fantasy-punk/` — только в `fantasy-punk-skin.css`; коммит и пуш —
только по просьбе владельца; ответы — по-русски.
