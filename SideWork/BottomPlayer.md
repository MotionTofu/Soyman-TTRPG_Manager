# Аудио-плеер внизу приложения — Аудит

Дата: 2026-08-30
Файлы: `audioPlayer.tsx`, `index.css:6069-6248`, `soundConsole.css:490-505`, `AppShell.tsx:388-393`

---

## Что это

`AudioPlayerBar` — фиксированная панель внизу экрана между сайдбаром (200px) и панелью поиска (320px). Показывается только GM (у игроков пустой слот). Содержит: транспорт (назад/играть/вперёд), название трека с полосой времени, разделитель, кнопки-действия (extras), индикаторы каналов.

Мобильная версия — `MiniPlayerBar`, отдельная капсула `position: fixed` над нижней навигацией.

---

## Нарушения инварианта системы

### 1. Радиусы (§1.1)

```css
border-radius: var(--card-radius) var(--card-radius) 0 0;
```

Панель имеет скруглённые верхние углы. По §1.1 «Система рисует прямой угол. Исключение — пользовательская настройка, §4.» Но §4 оговаривает: «переопределение действует **только на внешний угол карточки**. Всё внутри — прямоугольное всегда.» Панель плеера — не карточка, а глобальная обёртка. Скругление на ней — не пользовательское переопределение угла карточки, а элемент интерфейса, который §4 не покрывает. **Нарушение.**

### 2. Тени / blur (§1.2)

Нет явного `box-shadow` на `.audio-player-bar`. Но на мобильном `MiniPlayerBar`:

```css
background: color-mix(in oklab, var(--paper-2) 94%, transparent);
backdrop-filter: blur(10px);
```

`backdrop-filter: blur(10px)` — визуальное размытие содержимого под панелью. По §1.2 «Глубина — только инверсия и обводка. Свечения нет нигде, кроме одного элемента в неоновом режиме.» Blur — не свечение, но создаёт визуальную глубину через прозрачность + размытие, что по духу ближе к тени, чем к инверсии. **Пограничный случай.**

### 3. Обводка / разделитель (§1.3)

```css
border-top: var(--card-border-width) solid var(--line);
```

Соответствует §1.3 (2px внешний контур). Но `.audio-player-divider` использует:

```css
background: color-mix(in srgb, currentColor 22%, transparent);
```

Это не `--line`, а inline color-mix. Разделитель — 2px фоновый блок, а не line в 1.5px. **Расхождение.**

### 4. Шкала кегля (§1.6)

- Название трека: 13px, Label (Oswald), капс — корректно.
- Время: 10px, Data (JetBrains Mono) — корректно.
- Кнопки действий: 10px, Label, капс — корректно.

Скачок 13px → 10px = 1.3x при разной гарнитуре. §1.6 требует ×1.6. **Пограничный случай.**

## Проблемы компоновки

### 5. Хрупкий `padding-bottom`

```css
.app-content.has-player { padding-bottom: 72px; }
```

Высота панели зашита как 72px. Если высота изменится (другой язык, thêm кнопки) — контент перекроется или появится дыра. **Связь через магическое число.**

### 6. Магические числа `left`/`right`

```css
left: 200px;
right: 320px;
```

Привязка к ширине сайдбара и панели поиска захардкожена. При изменении ширины сайдбара (`.app-shell-live` использует 320px вместо 200px) панель поедет. Уже решено частично через `.app-shell-live .audio-player-bar { left: 320px; }`, но паттерн хрупкий.

### 7. z-index без системы

`z-index: 40` для панели. Модалки — 50, поповер полотна — 48. Порядок корректен, но数千ичные z-index без единой шкалы — источник будущих конфликтов.

### 8. `display: contents` на слоте

```css
.audio-player-slot { display: contents; }
```

Делает элемент недоступным для screen reader и не кликабельным. Решение проблемы grid item для `position: fixed` ребёнка, но с побочным эффектом.

## Accessibility

### 9. Транспортные кнопки без `aria-label`

```tsx
<button type="button" onClick={prev} disabled={...} title="Предыдущий трек">
  <NavIcon name="prev" />
</button>
```

Три кнопки (prev, toggle, next) используют `title`, но не `aria-label`. Screen reader прочитает пустой `<svg>` или ничего. **Недоступно.**

### 10. Слайдер без клавиатуры

```tsx
<span role="slider" aria-label="Перемотка" tabIndex={0} ...>
```

Есть `role="slider"` и `aria-label`, но нет `onKeyDown`. Стрелки влево/вправо не перематывают. **Частично доступно.**

### 11. Пустое состояние без `aria-live`

```tsx
<span className="muted">Ничего не играет</span>
```

Нет `role="status"` или `aria-live="polite"`. Смена состояния «играет → не играет» не объявляется screen reader.

## Несогласованность: десктоп vs мобильная капсула

| Параметр | Десктоп (.audio-player-bar) | Мобильный (.mini-player-bar) |
|---|---|---|
| Фон | `var(--card-band-bg)` (непрозрачный) | `color-mix(..., 94%, transparent)` + `backdrop-filter: blur(10px)` |
| Граница | `border-top: 2px solid var(--line)` | `border: 1px solid var(--line)` |
| Радиус | `var(--card-radius) var(--card-radius) 0 0` | `var(--card-radius)` (все 4 угла) |
| Содержимое | Транспорт + название + время + прогресс + разделитель + extras | Только название + play/next |
| ARIA | Slider на прогрессе | Нет |

Две панели — два разных подхода к одному функционалу. Владелец видит одно на десктопе, другое на телефоне — визуально говорят на разных языках.

## Мелочи

### 12. `opacity` вместо токенов

```css
.audio-player-time { opacity: 0.65; }
.audio-player-bar .muted { opacity: 0.75; }
```

Приглушённый текст — это `--muted` или `--on-surface-muted`, а не полупрозрачность. На тёмном фоне `opacity` может давать недостаточный контраст.

### 13. Акцент на мёртвой кнопке

Кнопка «Пульт» (`accent`) всегда залита акцентом, даже когда сессия не запланирована. Акцент на недействующем элементе — визуальный шум.

# ПЛАН ИСПРАВЛЕНИЯ

## Фаза 1 — Accessibility (высокий приоритет)

### 1.1 `aria-label` на транспортных кнопках

**Где:** `audioPlayer.tsx:507-520`

**Как:** Добавить `aria-label` на каждую кнопку. `title` остаётся для тултипов:

```tsx
<button aria-label="Предыдущий трек" title="Предыдущий трек">
<button aria-label={isPlaying ? "Пауза" : "Играть"} title={...}>
<button aria-label="Следующий трек" title="Следующий трек">
```

### 1.2 Клавиатурное управление прогресс-баром

**Где:** `audioPlayer.tsx:533-550`

**Как:** Добавить `onKeyDown`:

```tsx
onKeyDown={(e) => {
  if (e.key === "ArrowRight") seek(Math.min(duration, currentTime + 5));
  else if (e.key === "ArrowLeft") seek(Math.max(0, currentTime - 5));
  else return;
  e.preventDefault();
}}
```

### 1.3 `aria-live` на пустом состоянии

**Где:** `audioPlayer.tsx:491`

**Как:** Обернуть в `role="status"`:

```tsx
<span className="muted" role="status">Ничего не играет</span>
```

## Фаза 2 — Инвариант системы (средний приоритет)

### 2.1 Убрать `border-radius` с панели

**Где:** `index.css:6083`

**Как:**

```css
/* Было: */
border-radius: var(--card-radius) var(--card-radius) 0 0;
/* Стало: */
border-radius: 0;
```

Панель — не карточка, а часть глобальной обёртки. Скругление нарушает §1.1.

### 2.2 Заменить `opacity` на токены

**Где:** `index.css:6241`, `index.css:6221`

**Как:**

```css
/* .audio-player-time */
color: var(--on-surface-muted);

/* .audio-player-bar .muted */
color: var(--on-surface-muted);
```

## Фаза 3 — Компоновка (средний приоритет)

### 3.1 Вынести высоту панели в CSS-переменную

**Где:** `index.css:6069`, `index.css:1151`

**Как:**

```css

  --player-bar-height: 52px;
  height: var(--player-bar-height);

.app-content.has-player {
  padding-bottom: var(--player-bar-height, 72px);
}
```

### 3.2 Заменить магические числа `left`/`right`

**Где:** `index.css:6071-6072`, `index.css:6088-6089`

**Как:**

```css
:root {
  --nav-width: 200px;
  --search-width: 320px;
}

.audio-player-bar {
  left: var(--nav-width);
  right: var(--search-width);
}

.app-shell-live .audio-player-bar {
  left: 320px; /* или var(--dock-width) */
}
```
